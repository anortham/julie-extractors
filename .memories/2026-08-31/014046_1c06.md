## F# semantic facts packet complete

### WHAT

Implemented the approved BRE-42 Task 2 semantic-facts packet: F# relationships, identifiers, explicit and literal-backed type facts, generic type-argument usages, scalar literals, and complexity metrics. Added focused semantic tests and wired them into the existing F# test module.

### WHY

Task 2 consumes the registered F# implementation/signature parsers and declaration ids from Task 1. The extractor now publishes useful unresolved/local fact rows while preserving exact source evidence and avoiding workspace-global resolution.

### HOW

- Used grammar-proven `import_decl`, `application_expression`, `dot_expression`, `class_inherits_decl`, `interface_implementation`, `record_field`, `union_type_field`, `simple_type`, `generic_type`, `type_attributes`, and `const` child shapes from tree-sitter-fsharp 0.3.0.
- Resolved unqualified local calls and inheritance/field uses when the local symbol is unique; preserved qualified, receiver-qualified, imported, and interface targets as structured pending relationships with exact target spans.
- Emitted distinct call, member, variable, and type identifier occurrences with per-kind/span deduplication; recorded nested generic arguments against their outer type-use identifier.
- Limited type facts to explicit annotations and direct grammar literal constants; captured string, char, numeric, boolean, decimal, byte-array, and unit literal spans.
- Added F# complexity configuration for if/elif, guarded match/exception rules, try branches, for, and while nodes; pattern nodes are not counted.

### IMPACT

Direct F# semantic tests (12 including Task 1), `cargo check -p julie-extractors`, package Clippy with `-D warnings`, formatting, and `git diff --check` pass. The later `cargo xtask test language fsharp` command remains unavailable until Task 4 registers F# fixture support. The next task can add F# test-role extraction on top of these stable declaration/annotation facts.
