## Closed the three pre-release findings on `codex/extractor-gap-closure-plans`

### WHAT
Fixed the three items that blocked tagging the F#/Go/Rust/C# release candidate.
Nothing is committed; the work sits uncommitted in the branch worktree at
`.worktrees/extractor-gap-closure-plans`.

### Finding 1 — rustdoc fence recognition
`base/rust_doc_test_facts.rs` accepted only `rust`, `ignore`, `no_run`, and
`compile_fail` as the first info-string token, so real doc tests were dropped.
`rustdoc_mode` now follows rustdoc's own rule: a fence stays a doc test unless
every token is unrecognized. Added `is_rustdoc_attribute` (`rust`, `ignore`,
`ignore-<reason>`, `should_panic`, `no_run`, `compile_fail`, `test_harness`,
`standalone_crate`) and `is_rustdoc_edition` (`edition` + 4 digits).

Evidence: two new unit tests, plus two fences added to
`fixtures/extraction/rust/structural_facts/source.rs`. The regenerated golden
now carries three `rust.doc_test.v1` rows and proves a ` ```text ` fence stays
silent.

### Finding 2 — stale documented language inventory
`README.md` and `docs/site/index.html` claimed 38 languages; the CLI returns 40.
Both now say 40 and both lists gained `fsharp` and `qmldir`. The site coverage
table was rewritten with the real numbers from
`language-data-quality-report.mjs`, not a bumped denominator.

### Finding 3 — version bump and release notes
Three crates, `Cargo.lock`, and both workflow defaults moved 2.37.2 -> 2.38.0.
Wrote `docs/release-notes/v2.38.0.md` (classification: compatible) and indexed
it. Followed the prior candidate pattern: no Publication section, and the
"current published release" marker stays on v2.37.2.

### Discovered during the fix — recorded, not fixed
The collector reads `line_comment` only, so a doc test inside a `/** ... */`
block doc comment is missed. Proved with a `julie-extract scan`. Recorded as
`rust.doc_test_block_comments` under rust
`kind_coverage.structural_facts.open_gaps`, and named in `docs/languages/rust.md`
and the release notes. `open_gap_backlog` moved 47 -> 48.
