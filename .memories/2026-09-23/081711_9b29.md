## Added first-class `gomod` language for go.mod

**WHAT:** New language row `gomod`. The exact basename `go.mod` selects it, compared case-insensitively like `qmldir`. The grammar is `tree-sitter-gomod`, Git-pinned to camdencheek/tree-sitter-go-mod@2e886870 (MIT). The crates.io 1.0.1 release needs tree-sitter 0.20.

**WHY:** Closes the `go.module_manifest_language` gap on the `go` row. Before this change, every go.mod was scanned as unsupported.

**HOW:**
- `crates/julie-extractors/src/gomod/directives.rs` reads every directive line once. The extractor and the fact collector share that result. A line with an ERROR node publishes nothing, so `godebug` is never misread as `go`. Comments follow the `modfile` rules: leading comments, a suffix comment, `isIndirect`, and `parseDeprecation`. Retract rationale falls back to the block's comment.
- Symbols:
  - `module` becomes a `module` symbol.
  - `go` and `toolchain` become `property` symbols.
  - `require` and `tool` lines become `import` symbols.
  - The body span is the last value, so a `require` body hash tracks its version.
- Relationships:
  - An `Imports` edge runs from the module symbol to each require and tool symbol, with `dependencyKind` and `dependencyName` metadata (the npm/Cargo shape).
  - A file-path replace becomes a structured pending `Imports` row to `<path>/go.mod` (the Maven module precedent).
- Facts:
  - Each `require` line is a `manifest.dependency.v1` fact with ecosystem `go`, group `require`, and a new optional `indirect` BOOL key.
  - The other directives use the `gomod.{module,go,toolchain,replace,exclude,retract,tool,ignore}.v1` patterns, all with `query_family` `dependencies`.
- The grammar lexes a quoted value as a plain identifier. So the extractor unquotes values by their text, and emits the literals (carrier `<directive>.<role>`) and the `string_literal` regions itself.
- Open gaps on the `gomod` row: `gomod.godebug_directive`, `gomod.go_sum_checksums`, and `gomod.grammar_path_tokens`. The last one covers absolute replace paths, 1-character `ignore` paths, and a missing final newline.

**IMPACT:** Real-file scan: 128 local go.mod files gave 0 diagnostics, 754 symbols, 503 edges, and 762 facts. All gates pass.
