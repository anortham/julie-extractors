## Owned Go grammar forks pinned, gomod gaps closed, gosum language added

**WHAT**
- `tree-sitter-gomod` now points to `anortham/tree-sitter-go-mod@655fba88`, and the new `tree-sitter-gosum` points to `anortham/tree-sitter-go-sum@b1727178`. deny.toml allow-git has both. The grammar dependency policy lists both under Owned Grammar Forks, and camdencheek is removed.
- gomod: new `Directive::Godebug` (single and block forms). Each key is a `property` symbol named by the key, with the body span on the value and the signature `godebug key=value`. It also gets a `gomod.godebug.v1` fact with `key` and `value`. The three limit tests now assert rows with no diagnostics. The golden has godebug, an absolute replace (`/src/abs`), a one-character ignore path (`x`), and no final newline.
- The open gaps `gomod.godebug_directive`, `gomod.grammar_path_tokens`, and `gomod.go_sum_checksums` are removed. No new gaps.
- New language `gosum`, selected by the exact basename `go.sum` (case-insensitive). It is facts only: `FACTS_ONLY_CAPABILITIES`, all five flags false with typed exceptions. It publishes one `gosum.checksum.v1` fact per clean line, with keys module_path, version, go_mod, hash_algorithm, hash, incompatible, and pseudo_version, plus timestamp and revision for a pseudo-version. The pseudo-version check is Go's `pseudoVersionRE`.
- `EXTRACTION_CONTRACT_VERSION` ends with `.go-sum-checksums-v1`. The 3.5.0 ledger, plan task 3, README (42), rust-syntax-api (42), testing-strategy, go.md, gomod.md, and the new gosum.md are updated.

**WHY / HOW**
- No lockfile precedent exists in the repo. A go.sum line is a verification record, not a declaration, and it can keep stale modules. Symbols would add noise to symbol search, so the file is facts only. Consumers join to gomod dependency facts by module path and version.
- Facts come from the data collector (`collect_data_structural_facts`). `extract_gosum` returns `ExtractionResults::empty()`. A checksum node with `has_error()` is skipped.
- gosum is in DOMAIN_LANGUAGES (Rust test and mjs), in the domain-limited source-region list, and in the marker not_applicable list. It has no body.rs arm and no policy toml, because it has no comments and no literals.
