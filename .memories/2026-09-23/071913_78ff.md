## CI clippy failed on Rust 1.98 during the 3.4.0 release

**WHAT:** The first CI run on main (87782f29, run 35830448455) failed "Check clippy": Rust 1.98.0 (CI uses `dtolnay/rust-toolchain@stable`) adds `clippy::map_or_identity`, which flags `close.map_or(children.len() - 1, |close| close)` in `base/data_structural_facts.rs`. Local stable was 1.97.1, so local clippy passed.

**FIX:** `close.unwrap_or(children.len() - 1)`. Installed toolchain 1.98.0 side by side (default unchanged) and ran `cargo +1.98.0 clippy --workspace --all-targets --all-features -- -D warnings` (clean) and `cargo +1.98.0 fmt --all --check` (clean).

**LEARNING:** Before a release push, run clippy with the same toolchain CI resolves for `stable`; a local stable can lag the CI stable.
