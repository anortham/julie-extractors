## Removed the artifact-crate store (3.0.0 step 3)

### WHAT
- Deleted `crates/julie-extract-artifact/src/store/` (17 modules plus `reader_liveness/`) and the 22 `tests/store_*.rs` harnesses.
- Dropped `pub mod store;` from `lib.rs`.
- Dropped Cargo features `test-takeover`, `test-store-crash`, `test-store-maintenance-contract`, `test-store-contract`, the `[dev-dependencies]` self-reference, and dependencies `getrandom`, `rustix` (Linux table), `winsafe` and `machine-uid` (Windows table).
- Pruned store test names and features from `xtask/src/test_tiers.rs` contract plan and unit tests, and from the exact-list test in `xtask/tests/test_tiers.rs`.
- Rewrote `crates/julie-extract-artifact/tests/test_tiers.rs` so the wall-clock convention names only `test-perf`.
- `Cargo.lock` lost 51 lines (getrandom stays via the CLI).

### WHY
Plan `docs/plans/2026-09-15-remove-store-and-jsonl.md`, ADR `docs/decisions/2026-09-15-store-and-jsonl-retirement.md`: code-kb is the only consumer and never used the versioned family store.

### HOW
- Proved no outside callers first: `find_references` on `PidStatus`, `StoreLayout`, `STORE_SQLITE_SCHEMA_VERSION` (0 callers), `create_store_schema` (callers only under `src/store/` and `tests/store_*`), and `rg "artifact::store|store::"` over cli, extractors, xtask (empty).
- `MILLER_ALLOW_EXTRACTOR_DOWNGRADE` left with `store/connection.rs`; `rg MILLER_ crates xtask` is now empty.
- No `.github/workflows` step named a store test; `docs/contracts/cli.md`, `schema-principles.md`, `product-boundary.md` had no store lines left after Task 2.

### IMPACT
- `cargo build --workspace`, `cargo test -p julie-extract-artifact`, `-p julie-extract-cli`, `-p xtask`, `cargo fmt --check`, `cargo clippy --all-targets -D warnings` all pass.
- `docs/testing-strategy.md` still names `test-store-crash` commands (outside Task 3 file ownership; flagged for the lead).
- Task 4 (JSONL removal) and Task 5 (xtask release/perf/dogfood) can proceed.
