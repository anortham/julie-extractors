## Removed the JSONL export (3.0.0 step 4)

Plan: docs/plans/2026-09-15-remove-store-and-jsonl.md, Task 4. ADR: docs/decisions/2026-09-15-store-and-jsonl-retirement.md.

### WHAT
- Deleted `crates/julie-extract-artifact/src/jsonl.rs`, `tests/jsonl_contract.rs`, and `docs/contracts/jsonl-v1..v5.md`.
- Removed the `export` CLI command: `Command::Export`, `ExportArgs`, the `export` function, and the `Export` dispatch arm.
- Report contract: removed `ReportOperation::Export`, `ReportMode::Jsonl`, `ReportCode::ExportFailed`, `ReportCode::UnsupportedFormat`, `artifact.jsonl_schema_version`, and the always-null `input.format` / `input.output_path` fields. `ReportCode::ALL` is now 25 entries and `ERROR_CODES` 19.
- CLI internals: `artifact_access.rs` no longer threads a `jsonl_schema_version` argument through `open_artifact*`; `jsonl_counts` is gone; `ReportStream` (Stdout/Stderr) is gone because only the export wrote reports to stderr.
- xtask: dogfood no longer runs `export`, validates JSONL, or records `jsonl_*` / `export_duration_ms` metrics; performance baseline aggregates drop the same fields; `jsonl_contract` left the test tiers.
- Docs: cli.md, reports.md, README.md, docs/README.md, site index, architecture pages, CLAUDE.md and AGENTS.md now say SQLite is the only output.

### WHY
code-kb is the only consumer and never used the JSONL export. Keeping it cost a 2k-line module, a CLI verb, report fields, and dogfood/perf plumbing.

### HOW
Pure deletion. `find_references` proved `ReportOperation::Export`, `ReportMode::Jsonl`, `ExportFailed`, and `UnsupportedFormat` had no non-export users. `writer_perf.rs` kept its write-throughput and query-plan evidence and lost the export phase. `schema_contract.rs` lost its jsonl doc includes; the sqlite-v4 `test_detection` assertion stays under a new test name.

### IMPACT
- `julie-extract --help` lists scan, update, delete, info, languages, rebind.
- JSONL as a *source language* and the `.jsonl` scan spool are untouched.
- Left for other tasks: `xtask/src/release.rs` still lists the deleted jsonl docs in its package list (Task 5); `crates/julie-extract-artifact/src/model.rs:457` doc comment still says "JSONL key" (outside this task's file ownership).
