## Removed the store CLI command (3.0.0 step 2)

**WHAT**
- Deleted `crates/julie-extract-cli/src/store/` (15 files), the 13 `tests/store_*.rs` files, and the store contract docs (`store-v1.md`, `sqlite-store-schema-v1.md`, `sqlite-store-schema-v2.md`, `versioned-index-store.md`).
- `Command::Store` is gone; `DispatchOutcome` collapsed, so `run` returns `CommandOutcome` directly and `run_from_env` no longer routes parse failures through the store reader.
- Dropped cargo features `test-store-contract` and `test-store-maintenance-contract`, the `fs4` dependency, the `windows-capacity-store` CI job, and the CLI store entries in `xtask/src/test_tiers.rs` and `xtask/tests/test_tiers.rs`.
- Removed store-only dead code the deletion exposed: `validate_current_artifact_output`, `SnapshotCache::{remove, prune_dead_order_head, clear}`, `remove_cached_snapshot`, `clear_snapshot_cache`, the `JULIE_EXTRACT_STORE_TEST_RECORD_READS` read-recording hook, and the `process_status` wrapper in `watchdog.rs` (its only caller was `store/import.rs`).
- Docs: `docs/contracts/cli.md`, `README.md`, `docs/README.md`, `docs/site/index.html` no longer describe the store.

**WHY**
Plan `docs/plans/2026-09-15-remove-store-and-jsonl.md`: code-kb is the only consumer and never used the family store or JSONL export.

**HOW**
Pure deletion; no new abstractions. Kept `limits.rs` (still used by discovery, commands, and tests) and the artifact crate's `store` module for Task 3.

**IMPACT**
- `cargo test -p julie-extract-cli` (271 passed), `cargo test -p xtask` (121 passed), `cargo fmt --check`, and `cargo clippy -p julie-extract-cli -p xtask --all-targets -D warnings` are green.
- Task 3 has nothing left to relocate for the CLI: no CLI code calls `julie_extract_artifact::store::process_status` any more.
