## `julie-extract check` command (syntax check over stdin)

**WHAT:** New CLI command `check --path <path> [--json]`. It reads source text from stdin, picks the grammar from the path through the `syntax-api` feature's `parse_source`, and reports every recovery diagnostic as a `parse_failed` error with 1-based `start_line`, `start_column`, `end_line`, `end_column`, and `kind` in `details`. Clean parse: `ok`, exit 0. Errors: `failed`, exit 1. No grammar: `unsupported` with an `unsupported_file` warning, exit 0. Report carries `operation: check`, `mode: syntax`, `languages.language`.

**WHY:** code-kb must not carry its own tree-sitter grammars (user decision). It validates a proposed file body before writing it, so it needs the text on stdin, not a file on disk.

**HOW:** `julie-extract-cli` now builds `julie-extractors` with `features = ["syntax-api"]`. Added `ReportOperation::Check`, `ReportMode::Syntax`, `CheckArgs`, `fn check`, `fn syntax_diagnostic`. Four tests in `cli_contract.rs` (red first). Docs: cli.md, reports.md, README table, v3.0.0 release notes "Added", rust-syntax-api.md.
