## Guarded first raw recursive symbol-walker group

Advanced TODO item 12 by adding depth-budget enforcement to the direct per-language recursive symbol walkers that bypassed the shared base traversal helper.

- **WHAT:** Guarded Rust, Go, Java, C#, VB.NET, and C++ symbol walkers with the shared `tree_traversal` depth helpers; added a Rust regression for a deeply nested `function_item`.
- **WHY:** The RED test reproduced an actual Rust stack overflow before the guard, proving CLI panic isolation was not enough for adversarially deep syntax trees.
- **HOW:** Threaded `depth: u32` through the private walkers, checked `should_visit_tree_depth`, and used `child_tree_depth` before recursive child visits.
- **IMPACT:** The highest-risk direct symbol-walker slice is bounded; TODO item 12 remains partial because many `visit_node`, identifier, relationship, and data-language walkers still need migration.
