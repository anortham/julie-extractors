## Added shared tree traversal depth guard slice

Implemented the first slice of the depth-bounded traversal recommendation from the architecture audit.

- **WHAT:** Added an internal traversal depth budget module and wired it into `BaseExtractor` shared traversal helpers plus parse-diagnostic and header parser-comparison error walks.
- **WHY:** Recursive tree-sitter walks can exceed Rust stack safety under adversarially deep source trees; CLI panic isolation does not protect against process-aborting stack overflows.
- **HOW:** Centralized `TREE_TRAVERSAL_DEPTH_LIMIT = 1024`, guarded `walk_tree`, `traverse_tree`, `find_nodes_by_type`, `parse_diagnostics_for_tree`, and language-spec parse-error counting. Added tests around deep Rust block trees to prove shared helper traversal stops at the budget.
- **IMPACT:** Shared traversal entry points are now bounded. Remaining raw per-language recursive walkers are explicitly tracked in `TODO.md` item 12 for follow-up slices.
