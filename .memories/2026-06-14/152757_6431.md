## Completed TODO 13 CLI command orchestration split

- **WHAT:** Moved stable CLI helper families out of `crates/julie-extract-cli/src/commands.rs` into focused internal modules: `capability_snapshot.rs`, `reports.rs`, and `artifact_access.rs`. Added convention tests that keep those helper families from drifting back into `commands.rs`.
- **WHY:** `commands.rs` mixed command orchestration with report/error shaping, capability snapshot mapping, artifact opening/version checks, metadata reads, row totals, and JSONL count mapping. That made CLI contract changes harder to localize and review.
- **HOW:** Used red/green convention tests in `cli_contract.rs` for each helper family, then moved the code behind `pub(crate)` internal APIs while leaving public CLI behavior, report shapes, exit codes, and path policy unchanged. High-level command dispatch and scan/update/delete orchestration intentionally remain in `commands.rs`.
- **IMPACT:** `commands.rs` dropped to about 2,096 lines and now delegates capability snapshot, report/error, and artifact-access concerns to named modules. TODO 13 is documented complete in `TODO.md`, and the implementation plan checkboxes are complete.
