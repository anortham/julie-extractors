## Completed GLM remediation Task 2

### WHAT
- Added Vue SFC regression tests proving commented and string-embedded `fetch`, `axios.get`, and `path:` text does not emit facts.
- Added `ScriptSyntaxMask` in `web_structural_facts/js_object_scan.rs` for original-byte JS comment/string masking over Vue script ranges.
- Threaded the mask through Vue HTTP-client scans and Vue route-definition scans while preserving original `.vue` byte offsets.

### WHY
Vue script scanners were searching raw `.vue` text and using the Vue SFC tree for `is_ignored_syntax_range`, so JavaScript comments and strings inside `<script>` were treated as executable code.

### HOW
- Built a section-scoped JS mask that handles line comments, block comments, single/double/backtick strings, escapes, and regex literals.
- Passed the mask to `collect_http_client_requests` for Vue script sections and skipped masked fetch/axios identifiers.
- Built the same mask inside `collect_vue_route_definitions` and skipped masked `createRouter`, route array, and `path` hits.

### IMPACT
Task 2 acceptance is complete: ignored Vue script text stays silent, executable facts still emit, and full `cargo test -p julie-extractors vue --quiet` passes.
