- **HOW**: Added shared JS object ancestry filtering with `object_or_ancestor_value_property_matches`, applied it to React path/index route-object extraction and Vue route-object extraction, and compacted validated raw metadata JSON text before writing it into structural-fact JSONL records so key order remains stable without preserving unsafe whitespace.
- **IMPACT**: Nested metadata descendants are no longer reported as real frontend route definitions, index routes under metadata are suppressed, and structural-fact metadata exports remain one valid JSON object per JSONL line even when SQLite stores pretty/trailing whitespace JSON.
