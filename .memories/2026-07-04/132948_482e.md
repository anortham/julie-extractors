## Fixed same-span route fact persistence before v2.8.0 release

A review found that multi-verb route facts sharing the same source span could collapse when persisted because the framework structural fact ID only used pattern/capture plus span.

- **WHAT:** Added route-aware identity input to `fact_for_span`, covered Laravel `Route::match`, axum chained routes, and actix multi-method attributes in the CLI persistence contract, and refreshed order-sensitive route tests.
- **WHY:** SQLite persistence dedupes structural facts by `structural_fact_id`; same-span route variants need distinct IDs when their verb or effective route template differs.
- **HOW:** `identity_name` now includes deterministic `route_template`, `effective_route_template`, and `verb` metadata when present. Non-route facts keep the prior `pattern_id:capture_name` identity shape.
- **IMPACT:** Unblocks the v2.8.0 release path after local workspace, golden, capability, data-quality, clippy, formatting, doc-sync, and release-preflight gates passed.
