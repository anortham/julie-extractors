## Completed GLM remediation Task 1

### WHAT
- Added failing and now-passing regression tests for ASP.NET/C# dynamic route silence, Spring mixed static/dynamic mapping arrays, Java and Ruby dynamic client URL silence, and Django `re_path` normalization.
- Fixed collector-boundary guards so dynamic route/URL arguments no longer emit guessed partial facts.
- Added Java, C#, and Ruby `static_arg.rs` arms with grammar-backed allowlist tests.
- Normalized common Django named regex groups into `normalized_route_template`.

### WHY
Task 1 addressed P0 false positives where partial static string prefixes from dynamic expressions were emitted as route or client boundary facts, plus a missing Django join key for named regex routes.

### HOW
- Required whole-argument consumption after string-literal parsing in ASP.NET minimal/group and attribute route parsing.
- Made Spring annotation array parsing skip dynamic elements while keeping static siblings.
- Required full URI argument consumption for Java `URI.create` and rejected Ruby interpolation for `Net::HTTP` literals.
- Added a conservative Django regex normalizer for `(?P<name>...)` groups.
- Added Java/C#/Ruby static-argument allowlist arms for future AST-based collectors while keeping current text scanners guarded locally.

### IMPACT
Task 1 plan acceptance criteria are complete and verified; next work is Task 2 Vue SFC script silence.
