## Published v2.12.0 and prepared the v2.12.1 CI-closeout patch

`v2.12.0` published successfully from `3f00c92`, but the separate push-triggered Linux CI run failed after Rust 1.97 introduced seven stricter Clippy diagnostics.

- **Release:** Workflow `29103308762` succeeded for all four targets and published the live non-draft release.
- **Asset audit:** All four archive SHA-256 values matched GitHub metadata; embedded binary checksums passed; every archive contained 21 files including test-evidence v1 and the continuous-testing boundary.
- **Dogfood:** The downloaded Apple Silicon binary reported `2.12.0` and passed repository dogfood on 1,538 files with zero failed rescan files.
- **Root cause:** CI run `29103297807` failed only at Linux Rust 1.97 Clippy with one `manual_filter` and six `question_mark` findings. The same Rust commit did not emit them on macOS, confirming platform-specific lint behavior.
- **Fix:** Applied behavior-preserving `Option` rewrites across SQL, C++, CSS, GDScript, Lua, and Razor; bumped the patch candidate to `2.12.1`; recorded v2.12.0 evidence and prepared v2.12.1 notes.
- **Impact:** v2.12.1 is locally release-ready but intentionally not pushed or published until renewed approval for the changed release state.
