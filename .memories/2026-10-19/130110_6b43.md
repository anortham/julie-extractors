## julie 3.8.0 release prep: notes and test-tier fix

**WHAT:** Added `docs/release-notes/v3.8.0.md` (call argument counts, Rust type-fact fix, compatibility) and listed `crates/julie-extractors/tests/call_argument_counts.rs` in `FAST_INTEGRATION_TESTS` (`xtask/tests/integration_test_tiers.rs`).

**WHY:** `cargo test -p xtask` (a CI fast-gate step) failed: the new test file was in no tier. The 3.8.0 commit gate ran fmt, clippy, default, and contract, but not `cargo test -p xtask`.

**HOW:** Fast list, not a perf feature gate. The file has two 10 s ceilings (20,000-comparison call, 100-deep nesting); each case takes 1.2 to 2 s in a debug build, and the default tier runs only on ubuntu-latest. Rejected: a new `test-perf` feature on julie-extractors plus a perf-plan command and an xtask test change (larger, no gain).

**IMPACT:** Local CI equivalent passes: fmt, clippy `--all-features --no-deps -D warnings`, doc sync, language-data-quality `--strict`, `cargo test -p xtask`, `xtask test default`, `contract`, `certification`, `real-world-smoke`; `cargo xtask release preflight --version 3.8.0` ok (6 targets, 27 inputs).
