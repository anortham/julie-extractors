## v3.1.2 published with Windows ARM64; v3.1.3 adds Linux ARM64

**WHAT**
- v3.1.2 (commit `0dd4a87b`, tag `1173817c`) published 2026-09-20T16:41:13Z. Release run 35522724006: all five targets built; the `aarch64-pc-windows-msvc` job passed on its first run in 7m34s. Live assets verified in `docs/release-evidence/2026-09-20-v3-1-2-release.md`; `docs/release.md` pointer advanced to v3.1.2.
- v3.1.3 prep in the same commit: `aarch64-unknown-linux-gnu` on the native `ubuntu-24.04-arm` runner, added to the workflow matrix, `RELEASE_TARGETS` in `xtask/src/release.rs`, the workflow contract test, and `docs/release.md` (six targets). Version 3.1.3, notes in `docs/release-notes/v3.1.3.md`.

**WHY**
User asked for Linux ARM builds for Asahi Linux and Snapdragon hosts. The release doc says post-release evidence lands in a superseding patch release, so the v3.1.2 evidence rides with v3.1.3.

**HOW / LEARNED**
- `julie-extract check --path x.rs --json` reads the source from stdin. Passing only a path returns `status: ok` for any file, which is not a syntax verdict. The evidence smoke test must pipe the source in.
- The tree-sitter grammars and bundled SQLite compiled on ARM64 MSVC with no changes.

**IMPACT**
Six release targets after v3.1.3. First Linux ARM64 build proof is the v3.1.3 release run.
