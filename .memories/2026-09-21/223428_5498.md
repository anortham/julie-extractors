## QML object model: nested objects become symbols, plain bindings stop being symbols

Lane E of julie-extractors 3.2.0, tasks 1 and 2 of the Qt first-class plan.

**WHAT**
- A non-root `ui_object_definition` and every `ui_object_definition_binding` now emit a `Field` row.
  Name is the object's `id` when it has one, else the `type_name` text. Signature is
  `poll: Timer` or `Rectangle`. Metadata carries `object_type`, `binding_kind: "object"`, and
  `value_source_property` for the `Behavior on color` form.
- The object row is the parent of the object's members, so properties, functions, and nested
  objects hang off it instead of the file class.
- The root component keeps its `id:` `Property` row. Nested objects lose their separate `id:` row;
  the object row carries the id.
- An inline component's body object gets no field row; its members parent to the inline class.
- Plain property bindings are no longer symbols. The `qml.binding.v1` structural fact keeps them.
  Signal handlers stay `Function` rows and declared properties stay `Property` rows.

**HOW**
- `semantics::enclosing_object` and `semantics::object_has_class_row` decide which objects own a
  class row (root and inline-component body) and which get a field row.
  `is_inside_object_definition_binding` is deleted; nothing used it once bindings left.
- `QmlExtractor::push_object_symbol` builds the field row and reuses
  `relationships::object_id_binding` for the id.
- `receiver_can_resolve_locally` now accepts both id shapes: the class row's `id:` property and the
  object row that the id names. QML ids are file-scoped, so the old caller-scope equality test was
  dropped; the check is now "the file declares this id and the callee is a member of that object".
- `find_enclosing_symbol` replaces the hand-rolled walk in `find_containing_component`. Property-use
  resolution re-anchors to the nearest object row, while the relationship's `from_symbol` stays the
  nearest class, so no edge starts at a field row.

**IMPACT**
- Omarchy corpus: QML property rows fall from 10,346 to 2,357; 1,940 field rows appear; zero plain
  binding rows survive; `qml.binding.v1` facts stay at 7,459.
- `fixtures/extraction/qml/qt_symbols/source.qml` gains a nested object tree, a `Behavior on color`
  block, and a qualified `QQC2.Button`. That fixture is still unregistered in capabilities.json;
  the integration lane registers it.
