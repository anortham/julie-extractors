## Task 1 round-1 review fixes

### WHAT
Reworked the qmldir packet after lead review. Canonical `src/lib.rs`/`src/tests/mod.rs` now wire `qmldir` like peer languages; registry-local path/test modules are gone. `QmldirExtractor` now emits typed `qmldir.*.v1` StructuralFact rows for module, object/singleton/internal types, JavaScript resources, plugins/optional plugins, classname, typeinfo, depends, import, designersupported, prefer, and linktarget. Internal symbols are `Visibility::Internal`; classname is a plugin-class fact, and internal syntax is `<TypeName> <File>`. Added a directive-matrix test with negative controls. Added `SYMBOLS_ONLY_CAPABILITIES`, deny.toml approval, grammar policy documentation, and corrected downstream smoke wording.

### WHY
Review found the registry-local wiring was not canonical, directives were semantically incomplete/misclassified, DATA_ONLY claimed identifiers that are never emitted, and dependency policy/downstream evidence omitted the new git parser.

### HOW
Used the pinned tree-sitter command nodes, Qt qmldir contract, existing StructuralFact span/ID conventions, and existing generic dependency policy tests. Registry extraction now preserves extractor-provided facts before appending generic fact families; Task 4 can register the emitted pattern schemas without losing rows.

### IMPACT
Focused extraction tests (4), registry/API tests, dependency policy tests, locked check/metadata, cargo-deny, and real downstream path-dependency smoke all pass. `cargo xtask test language qmldir` remains the only expected gap because Task 5 owns capability/test-tier wiring. Full finding disposition and evidence are in the task report.
