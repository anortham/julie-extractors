## Pipeline routing and qmldir emitter-inventory corrections

### WHAT
Updated `crates/julie-extractors/src/pipeline.rs::detect_language_for_path` to delegate to the producer-owned `detect_language_for_source(file_path, "")`, with a focused test covering exact extensionless `qmldir`, arbitrary extensionless rejection, and normal `.h` routing. Added `pub(crate) const STRUCTURAL_FACT_PATTERN_IDS: [&str; 13]` in `crates/julie-extractors/src/qmldir/mod.rs` and made the directive-matrix test compare emitted fact IDs against that inventory.

### WHY
Certification/parser-upgrade paths still used an extension-only wrapper, so they could not route `qmldir`. Lead review also required one emitter-owned inventory for the 13 advertised qmldir fact IDs to prevent schema/emitter drift.

### HOW
TDD RED showed `detect_language_for_path("modules/Example/qmldir")` returned `Unsupported file extension`. GREEN delegates to the existing canonical path-aware detector without inventing a `.qmldir` extension or hardcoding CLI behavior. The constant lists module, object, singleton, internal, JavaScript resource, plugin, classname, typeinfo, depends, import, designer, prefer, and linktarget fact IDs; `push_fact` debug-validates IDs and the matrix test compares the exact emitted set.

### IMPACT
Focused pipeline basename test, `.h` source-aware/path behavior test, QML directive matrix, formatting, and diff checks pass. No golden or Task 4 files were edited by this packet. The worktree remains dirty from concurrent integration changes and no commit was made.
