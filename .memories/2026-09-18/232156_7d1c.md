## Release prep: julie-extract 3.1.1 (qualified call chain receivers)

**WHAT**
- Bumped `julie-extract-artifact`, `julie-extractors`, `julie-extract-cli` and `Cargo.lock` from 3.1.0 to 3.1.1.
- Regenerated 9 golden fixtures whose only changes are the qualified-call-chain receiver split: csharp/http_client, java/basic, powershell/basic, powershell/return_types, cpp/basic, cpp/cross_file, ruby/basic, ruby/backend_http_boundaries, zig/test_roles.
- Added `docs/release-notes/v3.1.1.md`, a `## 3.1.1` ledger entry (classification: compatible) in `docs/contracts/extraction-output-changes.md`, and one sentence at the `pending_relationships` row of `docs/contracts/extracted-data-v3.md`.

**WHY**
- Tasks 1-5 on branch `qualified-call-chain` made every language record `Q1.Q2 ... Qn.t(...)` as terminal `t`, receiver `Qn`, namespace `[Q1 .. Qn-1]`. The branch gate, fixture review and version bump close the release.

**HOW**
- `docs/contracts/extraction-output-changes.md` requires a ledger section per version whose output changes; no schema or JSON shape changes, so `EXTRACTION_CONTRACT_VERSION` and `EXTRACTION_IDENTITY_EPOCH` stay unchanged (lib.rs doc: bump only when the shape changes).
- Every fixture diff row satisfies the hard-gate rule (receiver split, new pending row, `.` separator, corrected C# terminal name). `powershell/return_types` was not on the pre-reviewed list but is `[Result]::new` gaining receiver `Result` (rule a).
- Java `basic` drops 2 resolved `relationships` rows that now surface as pending rows with receiver `Worker` and namespace `["fixture"]`; the duplicated pending pairs there match the pre-existing pattern for every other qualified call in that fixture.

**IMPACT**
- Gates green: fmt, xtask tests, default, contract, capability, golden, deny, `release preflight --version 3.1.1` (4 targets, 27 inputs).
- Survey scan of scratchpad `langs/` and `e2e/` with the 3.1.1 release build shows receiver `Inner` / namespace `["Outer"]` for every Task 1-5 language.
- Not tagged, not pushed: approval boundary for the lead.
