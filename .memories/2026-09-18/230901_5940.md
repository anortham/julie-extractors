## Task 5: C, PHP, Ruby, R split compound call receivers

**WHAT:** `c/relationships.rs`, `php/call_relationships.rs`, `ruby/relationships.rs`, `r/relationships.rs` now build qualified call targets through `UnresolvedTarget::from_qualified_text` with per-language separators (C `. ->`, PHP `:: -> .`, Ruby `:: .`, R `$ @`), falling back to the previous target when the text is not a plain identifier chain. One new test per language in `tests/<lang>/cross_file_pending.rs`.

**WHY:** `Outer.Inner.chain()` used to record a compound receiver (`Outer.Inner`, `Outer::Inner`, `Outer$Inner`), which no consumer can match to the nested symbol. Plan `docs/plans/2026-09-18-qualified-call-chain-receivers.md` in code-kb, Task 5.

**HOW:** PHP member calls take the chain only when the namespace is non-empty so `$this->run()` keeps receiver `this`; Ruby takes the chain only when it has a receiver. R never splits on `.` (lead ruling).

**IMPACT:** Ruby golden fixtures `fixtures/extraction/ruby/basic` and `backend_http_boundaries` now expect `Net.HTTP.new` (receiver `HTTP`, namespace `["Net"]`); regeneration is deferred to Task 6. Lead inline review clean; committed by the lead (parallel-lead-commit).
