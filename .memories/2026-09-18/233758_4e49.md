## Java duplicate-pending repair

### WHAT
Moved Java call traversal to one root-level pass in `JavaExtractor::extract_relationships` and removed per-class/per-method passes. Strengthened the qualified-chain unit test to assert one row per call, including a nested type call. Regenerated the Java golden outputs.

### WHY
The prior visitor traversed each method once through its containing class and once again at the method node, producing duplicate pending and structured-pending relationships for every unresolved Java call.

### HOW
Keep inheritance traversal in `visit_node_for_relationships`; execute `relationships::extract_call_relationships` once from `tree.root_node()`. This preserves recursive discovery while eliminating duplicate passes.

### IMPACT
Qualified Java calls now emit one pending row each. Focused Java unit and language-scoped golden tests pass. Full integration remains lead-owned.
