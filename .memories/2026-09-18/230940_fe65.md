## Task 2: Java, Kotlin, Go, PowerShell keep receiver and namespace on call chains

**WHAT:** `java/relationships.rs`, `kotlin/relationships.rs`, `go/relationships.rs` walk the nested `field_access` / `navigation_expression` / `selector_expression` chain with a loop and call `UnresolvedTarget::from_chain`; `powershell/relationships.rs` gains `qualified_call_target` that flattens `[Type]::Member.Method()` and `$var.member.Method()` chains through `from_qualified_text`. One new test per language in `tests/<lang>/cross_file_pending.rs`.

**WHY:** these extractors recorded only the terminal name for `Outer.Inner.chain()`, so no consumer could match the call. Plan `docs/plans/2026-09-18-qualified-call-chain-receivers.md` in code-kb, Task 2.

**HOW:** a call result, indexer, `this`/`super`, or generic call as chain head stops the walk (same as the C# reference); PowerShell skips `$this` so `$this.Run()` stays simple with its receiver type; type literals split on `.` (`[System.IO.Path]::Combine()` gives receiver `Path`, namespace `["System","IO"]`).
