## WHAT

Updated `UnresolvedTarget::from_qualified_text` validation to accept Unicode XID identifiers, including combining marks, and added Python extractor regressions for Unicode and underscore-qualified chains. Corrected 3.1.1 contract and release-note wording to name both affected tables and the Java resolved-to-pending rows.

## WHY

The former ASCII-only predicate rejected valid Python identifier segments. Python then fell back to a compound receiver, losing the namespace portion of a qualified call target.

## HOW

Used `unicode-ident` XID start/continue predicates and retained the prior ASCII compatibility set. Regression inputs use `café.répo.save()` and `_outer.inner.save()` through `extract_canonical`; existing call-syntax rejection remains covered.

## IMPACT

Qualified Unicode chains retain `receiver`, `namespace_path`, and normalized display structure without accepting expression syntax. The package gains a direct declaration for the crate already present in `Cargo.lock`.
