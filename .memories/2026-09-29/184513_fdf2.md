## 3.7.2 readiness review and fixes on fix/windows-path-identity

- **WHAT:** Reviewed the uncommitted Windows-path diff for a patch release. Fixed three confirmed issues:
  - Discovery perf in `discovery.rs` `same_file_as`: the identity probe now runs only on a name match.
  - Stale verbatim `root_path` from 3.7.1 artifacts: `refreshed_metadata(metadata, root)` writes the canonical root, and `rebind` uses a text compare again.
  - `reports.md` `schema_migration_required` wording.
- Also reverted the weakened `capability_snapshot_test` (back to == 42), documented the identity root gate and the heal rule in `cli.md`, and narrowed the non-UTF-8 test skip to macOS EILSEQ.
- **WHY:** The review found scans slow on large repos and mixed root spellings in one artifact.
- **HOW:** Adversarial review workflows, TDD red check on 3 new rebind_contract tests, full gates green (default tier 35s).
- **IMPACT:** Known limit: a hard link to the artifact under a different name is not detected. Pre-existing race (not fixed): a scan commit can overwrite a concurrent rebind's root_path/artifact_id; writer checks only producer generation.
