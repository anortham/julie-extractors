## WHAT

Candidate f5fe0291 passed all Linux and native Windows test tiers, workspace all-feature tests, ignored tests, clippy, quality, release builds, preflight, and package staging. Compatibility with published 3.7.1 is byte-identical across 18 extraction tables on both platforms. Windows warm default took 81 seconds; guest is shut off.

## WHY

Release-binary benchmarks found a fixable Linux regression when 4,000 source filenames match the artifact name: median unchanged scan 117.87 to 127.85 ms (+8.5%). Unix identity checks fetch metadata that the size check immediately fetches again. Full-repository scans differ only +0.5%, with identical fact counts and size.

## HOW

Reused force_cli worker for discovery.rs only: cache/reuse candidate metadata lazily for Unix identity and size checks, preserve exclusion priority and ignored-file laziness. Rejected dropping identity checks: they protect artifact aliases. Native Windows collision overhead was confirmed at +4.8% across 30 samples and requires native identity probes; avoid new FFI/dependencies to shave that cost.

## IMPACT

3.7.2 remains release preparation, not published. Initial verified code is f5fe0291. Raw evidence lives in target/release-readiness/3.7.2; Linux baselines use frozen-source at that commit. After the focused optimization, verify relevant CLI scopes on Linux/Windows, rebuild binaries, rerun compatibility/packages and timing comparisons, then commit final evidence and shut down Windows again.
