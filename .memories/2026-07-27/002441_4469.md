## Hardened the FK index invariant for composite keys

- **WHAT:** Generalized the schema contract test from single-column child keys to ordered foreign-key column prefixes.
- **WHY:** A future composite mutable foreign key must be served by an index with the complete child-key prefix; checking each column independently would either miss the real requirement or demand incorrect indexes.
- **HOW:** Grouped `PRAGMA foreign_key_list` rows by foreign-key ID and sequence, then matched the ordered columns against every index prefix from `PRAGMA index_list` and `index_info`.
- **IMPACT:** The regression guard now expresses SQLite's actual foreign-key lookup requirement and remains valid if the public artifact schema adds composite relations.
