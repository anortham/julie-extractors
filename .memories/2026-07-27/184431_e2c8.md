## v2.19.0 published and verified

Tagged `v2.19.0` at `9e162052` and published all four release assets. This closes the identifier target-resolution work (TODO #16) that ran through three adversarial review rounds with Codex and Grok.

### What shipped

- **Tier 3b `tier3_static_type` at confidence 0.70** — binds a reference whose receiver names a type directly (`Fixture.Create()`, `Color.Red`). Refuses nested types, non-public cross-file types, non-`static` members, mismatched namespace qualifications, and receivers shadowed by an enclosing parameter.
- **C# file-scoped namespace fix** — `namespace App.Core;` was never dispatched, so a 1,447-file corpus had **0** namespace symbols. Now 655, and types are correctly parented.
- Resolution contract version 2 → 3. SQLite schema 5, extract contract 4, JSONL 4 all unchanged.

### Two red gates closed on the way out

- `cargo xtask dogfood repo` had been failing since **2.18.0** — `xtask` kept a private duplicate of the JSONL allowlist that never got `reference_site`. Now imports `julie_extract_artifact::jsonl::JSONL_RECORD_KINDS`.
- `child_row_batch_avoids_per_file_statement_prepare_overhead` asserted `elapsed < 1750ms` from an **ungated** default-suite file. Failed at 2.42s on `0ceaaae5` (pre-dating this work) and 2.22s on `d941a489`, while passing locally. `perf_gate_is_feature_gated_out_of_default_suite` only checked that `writer_perf.rs` was gated, so a second ungated file with the same budgets walked right past it.

### How the leak was closed

`writer_performance.rs` now asserts only hardware-independent structure (one commit per write, every child row family persisted). A new `default_suite_tests_assert_no_wall_clock_budget` scans `tests/*.rs`, skips `#![cfg(feature = "test-perf")]` files and its own source, and fails on any remaining `Instant` reference. Verified it bites by planting an offending file.

### Impact

The default suite can no longer fail for being on a slow runner. Both writer throughput cases stay covered in the gated `writer_perf.rs` harness against 30s/15s regression floors.
