## Shipped TODO #16 slices 1–3: reporting leak closed, static-receiver tier added

Branch `fix/identifier-resolution-static-receiver` off `main` @ `058b166a`. Uncommitted.

### WHAT

**Slice 1 — reporting leak.** `resolve_identifier_items` skipped any identifier "covered" by a co-located pending/relationship edge regardless of whether that edge resolved, so a failed covering edge left the identifier with no `identifier_resolutions` row — neither `resolved` nor `missing`. New `propagation_owned_identifiers()` (`resolution.rs`) narrows the covered set, after the pending+propagation flush, to identifiers that actually have a `resolved` overlay row. Called from both `resolve_full` and `resolve_delta`.

**Slice 2 — re-baseline.** Full pass over Miller's workspace with the release binary (prior baseline was delta-maintained since revision 1 against head 104).

**Slice 3 — static/type-name receiver tier.** `Tier::StaticType` + `static_type_candidates()`. Stamps `tier = 3` with a distinct method `tier3_static_type` at confidence 0.70 — distinct because no `type_facts` row participates and `tier3_receiver` would misattribute the evidence. `applicable_tiers` gives `(Identifier, Call)` the tier (was `[Import, Global]`). `tier123_compatible_kinds(MemberAccess)` gained `Constant`/`EnumMember`. `RESOLUTION_VERSION` 2 → 3.

### HOW — the safety gate

`static_receiver_is_reachable()` refuses (a) a receiver type nested inside another **type** — a namespace/module parent does NOT count, which was a real bug caught by the C# fixture since block namespaces parent every type — and (b) a non-public type outside its declaring file. `visibility` was added to `CandidateSymbol` and loaded in `load_candidate_symbols`.

| member_access | 96 (0.2%) | 5,474 (12.1%) |

| overall | 34,242 (11.1%) | 45,612 (14.7%) |

`tier3_static_type` = 9,853 (predicted ~9,852). Identifiers with no overlay row: 63,821 → **0**.

Precision held on both reviewer objections: `NullLoggerFactory.Instance` binds only at the 6 sites in its declaring file, refusing all 18 cross-file ones; `Assert.Equal` (7,091), `Path.Combine` (1,691), `Assert.Single` (736), `File.WriteAllText` (416) all resolve to zero.

### OPEN ISSUE FOUND POST-IMPLEMENTATION

**TypeScript classes carry `visibility = NULL`**, so `matches!(visibility, Some("public"))` is false and the static tier is silently disabled for all cross-file TS receivers. Probed: rust `pub`/`pub(crate)` → public, go exported → public, python always public, **typescript NULL**. This is recall loss, never a wrong edge, but it is a silent per-language capability gap and the repo's data-quality bar requires it be recorded with a named closure. Not yet fixed — waiting on the Codex/Grok implementation reviews before batching fixes.
