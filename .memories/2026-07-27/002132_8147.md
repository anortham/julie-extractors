## Fixed schema-5 one-file delete amplification

- **WHAT:** Added leading indexes for every previously uncovered `CASCADE` or `SET NULL` child foreign key and a catalog-wide contract test that rejects future omissions.
- **WHY:** Deleting one file cascaded through `reference_sites`, then repeatedly scanned full `identifiers`, `relationships`, and `pending_relationships` tables because their `reference_site_id` foreign keys were unindexed.
- **HOW:** Added six indexes covering reference-site evidence, containing-symbol literals/sites, and language capability gaps; updated the schema authority fingerprint and explicit index contract.
- **IMPACT:** Restores indexed child lookups for incremental file replacement and prevents new mutable foreign keys from silently introducing full-table cascade scans.
