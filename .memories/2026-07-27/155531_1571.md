### Key evidence discovered while verifying
Probed visibility/signature emission across 6 languages with a scratch scan (`vischk2`). The static tier can only *produce* an edge where the extractor emits **both** type `visibility` and a standalone `static` member modifier:
- **C# / Java / JavaScript**: both present → tier works
- **TypeScript**: NULL visibility on the class *and* signature `make(): : number` with no `static` → fully excluded
- **Python**: `@staticmethod def make()` → "staticmethod" is one word, fails the standalone-word test
- **Rust**: `pub fn make() -> i32` → associated fns carry no modifier
This is what makes the per-language gap row the honest surface rather than a hard behavioral gate: the tier stays on everywhere (its refusals are language-agnostic and safe), and the gap row records that only C# is fixture-proven.
