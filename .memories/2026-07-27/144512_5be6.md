## Codex review overturned my slice 1 — TODO #16 rewritten around a static-receiver tier

Supersedes the earlier checkpoint's recommendation. `codex exec` (0.145.0, read-only) reviewed the rewritten TODO #16 and refuted the central proposal. I verified its strongest claim with my own SQL and it holds.

### What Codex got right

**Tier 4 discards the receiver** (`resolution.rs:708-725` keys only on terminal name + language + kind). My 92%-name-uniqueness metric measured the wrong thing: it proves a *workspace* name is unambiguous, not that the call site refers to a workspace symbol at all. Measured on Miller's artifact — of the 10,575 edges a bare `Method` widening would create, **3,135 (29.6%) have a receiver naming nothing in the workspace**:

- `Path.Combine` → `CanaryAggregate.Combine` ×1,691
- `Assert.Single` → `DiffTargetsTests.Single` ×736
- `File.ReadAllText` → `EditApplier.ReadAllText` ×160

That violates `docs/contracts/sqlite-schema-v4.md:495` ("a wrong edge is worse than a missing one"). **Accepted doubt-pass finding 6 was right; my rewrite was wrong to call it merely unmeasured.**

Also correct from Codex:
- Slice 2 in isolation yields **4** sites, not 3,853 — enum/class symbols carry no type facts, so the receiver never binds. I had counted name matches, not funnel survivors.
- `partial` means delta **or** gating (`resolution.rs:1027`). Artifact has `last_full_revision=1` vs head revision **104** — my "measurements are from a complete pass" was unproven.
- `csharp/factory.rs` does not exist; the real path is `crates/julie-extractors/src/factory.rs`.
- Miller classifies any overlay target as exact regardless of the 0.55 tier confidence, so precision matters more than recall downstream.

### The better fix both of us missed

`resolve_receiver_symbols` (`resolution.rs:731`) binds the receiver only via the caller's scope chain then file top-level. When the receiver **is a type name** (`JulieDbFixture.CreateForEdit`, `SomeEnum.Value`), it lives in another file and never binds — so tier 3 declines. **There is no static/type-name receiver path.** Measured yield, with a structural correctness proof and zero name-only matching:

| site shape | candidates | terminal name is a direct member of the named type |
|---|---|---|
| `call` with type-name receiver | 3,064 | **2,891 (94.4%)** |
| `member_access` with type-name receiver | — | **6,669** (3,557 enum_member, 2,567 constant, 545 property) |

~9,560 C# sites, and it declines all 3,135 external-receiver cases by construction.

Added contract/consumer impact (`RESOLUTION_VERSION` bump + full backfill, Miller's exact-classification) and adversarial fixture requirements to verification.
