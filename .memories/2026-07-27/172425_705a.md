## Closed both round-2 wrong-edge findings by fixing a C# extractor bug underneath them

Round-2 verdicts: Grok SHIP (2 doc nits), Codex DO NOT SHIP (3 criticals). All closed. Branch `fix/identifier-resolution-static-receiver`, uncommitted.

### Codex critical 3 — static refusal was unsound (CONFIRMED, fixed)
C# signatures embed arrow bodies and field initializers, so `public int TotalCount => Kinds.Sum(static kind => kind.TotalCount)` carried a standalone `static` and my word-split accepted an instance property as static. 16 such symbols in the corpus. `contains_static_modifier` now scans only the *modifier prefix* — after stripping leading `[...]` attribute groups, up to the first `(`, `<`, `=`, `{`, or `"`. Cost: 0 bindings.

### Codex critical 1 — delta ownership mis-scoped (CONFIRMED, fixed)
`propagation_covered_identifiers` was scoped to `scope.changed_file_ids` while `worklist_resolved_identifiers_by_names` matches by name across the whole workspace. An identifier in an unchanged file could look unowned and have a correct propagated target overwritten. Now threaded `scope_files` (the `delta_scope_files` union) through `resolve_delta`.

### Codex critical 2 — mechanism right, conclusion wrong; then fully closed anyway
Both sub-cases reproduced synthetically. But the measured claim was wrong: all 30 qualified-receiver bindings were *correct* fully-qualified workspace references (`Miller.Server.Hosting.LeaderIdentityFile.Write`), so a blunt refusal would have destroyed 30 right edges for 0 measured wrong ones.

**Root cause found underneath it:** `crates/julie-extractors/src/csharp/mod.rs` dispatched `namespace_declaration` but NOT `file_scoped_namespace_declaration`. Miller's corpus is entirely file-scoped, so it had **0 namespace symbols** and every type had a NULL parent — the artifact simply had no namespace to compare against. Two fixes:
1. Dispatch `file_scoped_namespace_declaration` to `extract_namespace`.
2. The grammar leaves file-scoped declarations as *following siblings*, not children, so `walk_tree` now adopts the namespace as `sibling_parent_id` for the rest of the level. Corpus went 0 → **655** namespace symbols.

Then plumbed the qualification end-to-end: `receiver_qualifier_before_identifier` walks the separator chain leftward in extraction; stored in `metadata_json.$.receiver_qualifier`; `IdentifierWorkItem`/`UnresolvedEdge` carry it (pending side reuses the already-persisted `target_namespace_json`); `qualifier_matches_namespace` requires the written qualifier to be a **suffix** of `declared_namespace_path` (walking Namespace/Module ancestors), stripping `global::`.

**Shadowing parameter** closed with data already present: `scope_binds_receiver_name` walks the caller-scope chain through callables and refuses when a parameter name equals the receiver, parsing the parameter list nesting-aware (`split_top_level`, `top_level_parameter_list`).
