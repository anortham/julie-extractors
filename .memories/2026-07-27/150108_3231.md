## Three-model consensus reached on TODO #16; Grok corrected my yield measurement and safety claim

Third review (`grok-4.5`, read-only) on the static-receiver proposal. It found two errors in my round-3 work; I verified both with my own SQL and both hold.

### Grok's corrections (verified, accepted)

**1. My 2,891 measured the wrong rule.** I joined on names unique among all C# callables *and* required type membership — a strictly narrower filter than the rule I proposed. The proposed rule (unique workspace type receiver + exactly one direct child with the terminal name) yields **6,086** calls, 7,102 if overloads are allowed. So I understated recall while overstating safety. Reproduced exactly: `6086|7102`.

**2. "Declines external receivers by construction" is false.** The rule declines receivers with *no* workspace type of that simple name (`Path`, `Assert`, `StringComparison` → zero workspace types, safe). It does **not** decline external receivers whose simple name collides with a workspace type. Live existence proof: `NullLoggerFactory` is a `file static class` test stub defined once in `tests/Miller.Tests/Server/CallToolFilterTelemetryTests.cs`; 6 of its receiver sites are in that file and the rest span 7+ other test files where the real referent is `Microsoft.Extensions.Logging.Abstractions.NullLoggerFactory`. Those would be wrong edges — the tier-4 failure relocated from method names to type names.

Also accepted: `applicable_tiers` for `(Identifier, Call)` is `[Import, Global]` (`resolution.rs:545`), so the receiver path never runs for call identifiers — the plan omitted that. And the static path must be a **new filter with its own method string**, not a widening of `resolve_receiver_symbols`, or static bindings get mislabeled `tier3_receiver` and misreport type-fact involvement.

### Consensus state

- **All three agree**: never widen `tier4_compatible_kinds(Call)` with `Method`.
- **All three agree**: the static-receiver gap is real and is the right direction.
- **Grok alone** caught that round 3 relocates rather than eliminates the round-1 objection. Verdict: SOUND WITH CONDITIONS.
