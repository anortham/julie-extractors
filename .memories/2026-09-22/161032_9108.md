### WHAT
Fixed spacing, alignment, and contrast issues on the GitHub Pages documentation site in `docs/site/index.html` and `docs/site/style.css`:
- Removed `min-height: 78vh` and `align-items: end` from `.hero` (and `min-height: 70vh` on mobile) to eliminate the large top void above the hero title.
- Replaced the reused `.metrics-note` styling in `#consume` with a dedicated `.consume-notes` container providing 24px top spacing, `min(1120px, 100%)` width alignment, readable text contrast (`rgba(255, 255, 255, 0.78)`), distinct `#eb9a5f` link colors, and dark-theme inline code badges.
- Fixed `.feature-strip` to 2 columns (`repeat(2, minmax(0, 1fr))`) matching its 2 pillar children, eliminating the empty 3rd ghost column.
- Changed `.prose` to `.split-copy` in `#languages` for symmetrical 2-column layout and 1120px grid alignment matching `#what` and `#evidence`.
- Added `scroll-padding-top: 64px` to `html` so anchor jumps clear the fixed navbar.
- Added link styles for `.limits a`.

### WHY
The landing page hero had an awkward empty top section due to bottom alignment in a 78vh grid, and release notes under the command grid had zero margin, unreadable dark text on a dark background, and an unintended table-border line.

### HOW
Updated `docs/site/style.css` and `docs/site/index.html` with responsive styles and proper grid/flex layout parameters.

### IMPACT
Cleaner presentation, readable copy, and better user experience across desktop and mobile on the GitHub Pages documentation site.
