## WHAT

Made QML receiver-call resolution component-aware and replaced the same-line ownership scan with the shared interval index.

## WHY

QML component scopes isolate sibling inline-component ids, and JavaScript locals shadow ids. The extractor previously resolved both cases to unrelated local functions. The first ownership repair used a linear span scan, which would regress extraction performance.

## HOW

Relationship extraction builds filtered class and object `ContainingSymbolIndex` instances once. Receiver resolution now requires the referenced id to belong to the caller component or an ancestor, and rejects a receiver declared as a caller local.

## IMPACT

The extractor avoids false concrete Calls edges for sibling component ids and local shadowing while retaining interval-index lookup performance. Inaccessible same-file targets still do not emit structured pending calls; lead should decide whether the broader pending pipeline should model those.
