## Closed C++ external-review regressions

### WHAT
- Excluded `Q_NULLPTR` from preprocessing so ordinary defaults, assignments, comparisons, literal/type extraction, and original spans stay intact.
- Restored released broad declaration macro recognition while preserving only macros whose arguments are safe runtime expressions. Typed `Q_D`, `Q_Q`, and `Q_FOREACH` remain declaration-preprocessed after a red/green parser test.
- Corrected stale C++ Qt documentation around function labels and `Q_UNUSED` normalization.

### WHY
External review found that Q_NULLPTR padding could alter parsed text and that a finite allowlist dropped common Qt/KDE declaration macros.

### HOW
Regression tests cover Q_NULLPTR expressions, omitted-semicolon Q_UNUSED call retention, restored declaration macro samples, typed Qt declaration macro forms, and ordinary labels. The runtime denylist is narrowed by actual parser evidence rather than macro-name convention.

### IMPACT
C++ corpus parity is restored or improved: Kirigami remains 102 files, 0 failed, 31 diagnostics; Plasma is 1050 files, 0 failed, 297 diagnostics versus v3.3's 298. Scoped macro tests (47), symbol tests (28), and C++ golden verification pass.
