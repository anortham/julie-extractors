## Completed C++ Qt release review fixes

### WHAT
- Fixed `Q_PROPERTY` metadata loss for `DESIGNABLE`, `SCRIPTABLE`, `STORED`, `USER`, and both scalar and tuple `REVISION` values.
- Restricted macro blanking to Qt declaration syntax while retaining `Q_DECLARE_*`, `Q_DISABLE_*`, and `QML_*` declaration families; runtime macros such as `Q_ASSERT(helper())` retain nested call identifiers.
- Corrected scanner handling for numeric digit separators and character literals.
- Fixed lower-case `signals:` and `slots:` rewriting in ordinary functions by recognizing them only at class-member brace depth; template and namespace class headers remain supported.
- Added deterministic long-line macro-scan coverage and regenerated the scoped C++ Qt header golden.

### WHY
The new C++ Qt scanner could discard ordinary-C++ call facts, turn valid labels into parser errors, and lose standardized Qt property semantics. Its line-prefix lookup also scaled quadratically on long physical lines.

### HOW
- Added focused unit regressions for each lexical and extraction case.
- Used class-body brace depth for lower-case Qt section aliases, preserving uppercase Qt syntax macros independently.
- Preserved source byte positions and fixture output while adding a property with all new metadata attributes.

### IMPACT
The Qt C++ release path now preserves ordinary C++ semantics and richer Qt metadata. The performance owner measured the line-prefix optimization at 4.02s to 2.40s p95 for a 169KB one-line 10k-member Qt input. Scoped suites and C++ golden verification pass.
