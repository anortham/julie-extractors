## WHAT

Corrected the two QML ownership regressions identified by external review.

## WHY

The generic interval index prioritizes Class rows over Field rows, so nested object bindings resolved to the wrong owner. Inline component inheritance still chose a class by start line.

## HOW

Built exact start-byte owner maps once per extraction. Object lookup anchors inline-component bodies to their inline declaration and walks enclosing QML object nodes while skipping grouped blocks without rows. Inline inheritance uses the class anchor map.

## IMPACT

Nested `parent.x` and `this.x` resolve to the correct object property, and same-line inline components emit `extends` from their own class.
