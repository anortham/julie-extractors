## Wave 7 task 21: the pre-existing C++ header defects

Three defects fixed, each at one shared point, after a re-measure showed which remained.

- **21a forward declarations.** `cpp/mod.rs::extract_symbol` now returns no symbol for a `class_specifier`, `struct_specifier` or `union_specifier` without a `field_declaration_list` child (`has_member_list`). `class Units;` and `class ColumnView *view;` name no new type. The ERROR-node recovery and the friend path are untouched.
- **21b one row per declared constructor and destructor.** `extract_declaration` builds the row from the `field_declaration`, then the tree walk reached the child `function_declarator` and built a second row. `own_declarators` now marks that declarator processed whenever the declaration produced a symbol, the same way `declarator_belongs_to_function_definition` stands down inside a definition. Because the declaration row is now the only row, its two latent defects were fixed too: the destructor signature no longer keeps the trailing `;`, and both the constructor and the destructor take their access level from `extract_cpp_visibility` instead of a hardcoded `Public`.
- **21c modifier leak and lost return types.** `extract_method_modifiers` pushed the declaration's parent AND grandparent (the class body) into the nodes it scanned, so one member's `explicit`, `static` or `override` became a modifier on every method of the class. It now takes the member's own declaration through `function_declarators::enclosing_declaration`, which walks up only through `pointer_declarator`/`reference_declarator`. `method_return_type` reads the return type from that same declaration when the `function_declarator` the symbol is built from carries none, so `void ping() const` keeps its `void`. `override` is a trailing specifier now (`void paint() override`), never a leading modifier.
- **21d `Q_EMIT` variable rows.** Already zero on both corpora, no work needed.

**Goldens changed on purpose.** `cpp/basic` and `cpp/test_roles`: 27 signatures and 25 type-inference rows. Every change is a leaked modifier removed, a return type restored, or `override` moved after the parameters. No symbol row was added or removed.

**Verification.** `cargo test -p julie-extractors --lib` 4132 passed. `cargo xtask test language cpp` 179 passed, `golden` 8 passed. `cargo fmt` and `cargo clippy -D warnings` clean.
