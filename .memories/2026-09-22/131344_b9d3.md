## WHAT

Fixed QML relationship ownership when several QML objects start on one source line.

## WHY

`find_enclosing_symbol` selected the first eligible symbol sharing an object start line. A same-line inline component handler was therefore attributed to the outer component.

## HOW

The owner lookup now chooses the smallest requested-kind symbol whose byte span encloses the AST object. Added same-line and multiline inline-component handler regression coverage.

## IMPACT

Calls and property uses that fall back to enclosing object ownership now select the correct QML class or object row. The QML language guide's documented same-line ownership limit can be removed after lead review.
