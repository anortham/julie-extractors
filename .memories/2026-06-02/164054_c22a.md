## Pruned external ECMAScript pending calls

- **WHAT:** Added source-aware import classification for TypeScript and JavaScript pending-call extraction. Package, `node:*`, and alias imports no longer emit cross-file pending call rows; project-relative imports still emit structured pending relationships.
- **WHY:** Openclaw dogfood showed most remaining TypeScript pending rows came from external imports, especially `vitest`, which the current artifact cannot resolve as project-local symbols.
- **HOW:** Added a shared ECMAScript import source classifier, cached import binding sources alongside binding names, and gated direct/member pending targets by project-relative import source.
- **IMPACT:** Fresh Openclaw scan pending rows dropped from 316,272 to 151,527 and scan time improved from 90.10s to 86.25s while preserving relative-import pending rows.
