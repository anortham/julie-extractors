## Pruned external pending relationship noise

- **WHAT:** Added Swift external-symbol pruning for standard/framework targets and shared ECMAScript global pruning for TypeScript/JavaScript direct calls and constructors. Also fixed TS/JS `new Foo()` local constructable resolution so same-file classes named like globals still produce `Instantiates` relationships.
- **WHY:** Openclaw dogfood showed large pending relationship volume, especially TypeScript built-ins and Swift standard/framework symbols, but those rows do not represent project cross-file relationships and add artifact/write noise.
- **HOW:** Added fixture-backed tests for Swift standard protocols/framework calls, ECMAScript globals, and local same-file global-name collisions; added `SwiftImportContext`, `is_ecmascript_global_direct_target`, and constructable lookup in JS/TS `new_expression` relationship extraction.
- **IMPACT:** Openclaw pending rows dropped from 151,527 to 119,945. Repeat release dogfood scanned in 90.56s with 382 MB max RSS; wall time remains noisy and row pruning is not the dominant runtime bottleneck.
