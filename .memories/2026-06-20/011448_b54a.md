## Fixed Razor component file symbols

- **WHAT:** Added extraction of a top-level Razor component symbol for `.razor` files, named from the filename. Refreshed Razor golden fixture outputs.
- **WHY:** Downstream Miller symbol lookup could not resolve component names such as `ProjectTestsDashboard` because the extractor artifact had no filename-derived component/type symbol.
- **HOW:** `RazorExtractor::extract_symbols` now emits a public `class` symbol before walking child nodes. The symbol uses `signature: component <qualified-name>`, `metadata.type: razor-component`, and `metadata.qualifiedName`. Explicit `@namespace` is used for the qualified name when present; otherwise the simple filename-derived component name is used. The serialized kind remains `class` to avoid widening the public symbol-kind contract.
- **IMPACT:** Fresh artifacts now contain inspectable top-level symbols for Razor component files, making Miller's virtual filename fallback unnecessary for updated extractor output. Golden fixtures also now show the component as the containing symbol for file-level Razor identifiers and relationships.
