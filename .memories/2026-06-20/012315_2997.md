## Fixed GDScript resource-path extends implicit class symbols

- **WHAT:** Added GDScript extraction support for top-level `extends "res://..."` statements when synthesizing the filename-derived implicit class symbol. Added focused regression coverage and refreshed the GDScript cross-file golden fixture.
- **WHY:** Resource-path extends scripts are still Godot scripts with a public file identity. Without an implicit class row, downstream tools cannot inspect the script by filename, matching the Razor component failure pattern.
- **HOW:** `GDScriptExtractor::extract_symbols` now delegates extends target extraction to `extract_extends_base_class_name`. It preserves the existing typed-target path (`extends Node`) and falls back to parsing the `extends_statement` text, stripping single or double quotes from resource paths. The synthesized symbol keeps `kind: class`, `signature: extends res://...`, and `base_types/baseClass` metadata.
- **IMPACT:** Updated artifacts now emit a top-level class row for resource-path extends scripts, and child functions are parented under that implicit script class. The `gdscript:cross_file` fixture records the new class and extends pending relationship evidence.
