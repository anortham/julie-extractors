## Fixed structural fact review findings

- **WHAT:** Fixed four reviewed extraction bugs: ASP.NET absolute action routes no longer combine with controller routes; named-only ASP.NET HTTP verb attributes emit bare method facts; fetch only treats top-level `method` as the HTTP verb; commented/string pseudo-imports no longer gate axios/router request facts.
- **WHY:** The local unpushed commits introduced contract regressions in route and HTTP client structural facts, which would have produced incorrect SQLite/JSONL artifact rows for downstream consumers.
- **HOW:** Added targeted regression tests first, then tightened ASP.NET attribute argument parsing and route joining, constrained fetch method extraction to the top-level options object, and taught JS import detection to skip comments/strings before matching import syntax.
- **IMPACT:** Restores artifact correctness for the reviewed edge cases and adds focused test coverage through crate tests plus a rebuilt CLI scan against SQLite output.
