## Updated Workflow Checkout Actions to v5

- **WHAT:** Updated CI and specialist-gates workflows from `actions/checkout@v4` to `actions/checkout@v5`, and added an xtask convention test requiring checkout v5 across all workflow files.
- **WHY:** GitHub Actions CI passed but emitted a Node.js 20 deprecation warning because checkout v4 runs on Node 20. The release binary workflow was already on checkout v5.
- **HOW:** Added `workflow_actions_use_node24_ready_checkout` in `xtask/tests/commands_contract.rs`, observed it fail against checkout v4, updated `.github/workflows/ci.yml` and `.github/workflows/specialist-gates.yml`, then reran static and xtask tests.
- **IMPACT:** CI should no longer emit the Node 20 checkout warning, and future workflow changes are guarded by a convention test.
