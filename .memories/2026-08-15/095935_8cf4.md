## Profile-aware one-file performance gate

The one-file resolution oracle now distinguishes optimized product performance from debug test overhead without weakening the Release contract.

- **WHAT:** Renamed the existing 5,000 ms ceiling as the Release ceiling, added a 20,000 ms debug ceiling, and selected/report the active profile and ceiling in the assertion.
- **WHY:** The exact debug test measured ~11.6 seconds because it launches the unoptimized dev-profile CLI; the exact Release test measured ~2.84 seconds and passed.
- **HOW:** Used the existing `cfg!(debug_assertions)` profile-aware ceiling pattern from `tests/resolution_perf.rs`. The test still requires scoped mode, one changed file, and semantic digest equality.
- **IMPACT:** Both exact debug and Release focused tests pass; the 5,000 ms Release gate remains unchanged, while debug runs retain a 4x measurement-derived ceiling for useful regression coverage.
