## WHAT

Frozen the second performance-recovery slice at the `finish_exact` / `stream_resolution_diff` boundary. Eligible scoped runs will compose a completed `ResolutionScratchWriter` delta directly from the frozen predecessor overlay and touched scratch rows. Forced-full, initial-base creation, and scoped fallback continue through `finish_exact` and `stream_resolution_diff` unchanged.

## WHY

The post-batching public replay still spends 7.978 seconds resolving, and the corrected profile measured 5.562 seconds in full exact finalization. The current scoped path materializes prior state, scalar-validates every identifier, writes a 119.8 MB exact database, validates it, then diffs it back to a small base-relative delta.

## HOW

The direct composer must output the same existing base-relative scratch format, not a predecessor increment. It carries prior delta rows only for current visible untouched sources, replaces touched identifiers/pending rows by comparing them with the bound base, emits pending tombstones where the current effective row is absent but base has one, accounts for removed source versions, and produces the same canonical gap facts. It performs set-based effective totality and target-visibility validation. `ResolutionScratchWriter` retains ordering/count/integrity/incomplete-file guarantees. Downstream `ResolutionScratchReader`, rebase threshold, fenced publication, heartbeat, CAS, terminal logging, and reports remain unchanged.

If rebase policy fires, build the exact rebase scratch by applying the bound base plus direct delta under current manifest visibility, then reuse the existing rebase publication path. If scoped prerequisites drift or are unavailable, use the forced-full oracle path.

## IMPACT

This removes full-corpus exact materialization from ordinary scoped updates without weakening correctness or changing Store/CLI/MCP schemas. The initial RED must prove a scoped public resolve no longer crosses the full-finalization boundary, while forced-full still does; semantic/delta/gap equivalence, totality, target validity, cleanup, and rebase remain mandatory gates.
