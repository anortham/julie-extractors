## WHAT

Replaced magic relationship metadata attestation with the typed `Relationship.reference_site_is_exact` field across all relationship producers and the CLI artifact mapper.

## WHY

User metadata could forge exactness, and the internal `reference_site_provenance=target_token` marker leaked into exported `metadata_json`.

## HOW

- Added a serde-defaulted boolean matching `StructuredPendingRelationship`.
- `create_relationship_at_target` is the only relationship path that sets the field true.
- Broad constructors and all direct provider literals set it false.
- `map_relationships` gates target-token spans only on the typed field.
- Removed both metadata attestation methods and all production marker reads/writes.
- Added constructor/deserialization and scan-to-SQLite regression coverage.

## IMPACT

Relationship exactness is now an explicit producer contract. Arbitrary metadata cannot change canonical site identity, and exact relationships no longer export a structural marker as user metadata.
