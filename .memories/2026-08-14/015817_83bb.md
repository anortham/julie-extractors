## Added a Windows Compatibility section to the agent guidelines

**WHAT:** Added a "Windows Compatibility" section to `CLAUDE.md` and `AGENTS.md`, placed before the "Documentation" section.

**WHY:** The user fixed a long series of real Windows defects (path separators, verbatim `\\?\` prefixes in SQLite URIs, delete-while-open, `FlushFileBuffers` access, pid liveness cost, `#[cfg(unix)]` test gating). They asked for standing guidance so future work keeps Windows in mind.

**HOW:** Mined the pitfalls from the actual fix commits (01f80842, cf1280fa, d1319fde, d50e1359, 76320dfd) instead of a generic checklist. Eight bullets, each stating the Windows behavior and the required practice.

**IMPACT:** Future agents get repo-proven Windows rules in both guideline files. `scripts/check-agent-doc-sync.sh` confirms the two files stay byte-equivalent.
