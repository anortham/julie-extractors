## WHAT

Prepared the complete julie-extract 2.33.2 Windows reliability fix on `main`.

- Reused a long-lived coordinator connection and added bounded `SQLITE_PROTOCOL` retry around complete read-only lazy operations: coordinator/store construction, reconcile, writer eligibility, normal store readers, resolution base readers, and scratch readers.
- Sampled production lease-acquisition time only after `BEGIN IMMEDIATE` succeeds.
- Made writer heartbeat renewal retry transient failures and reclaim only an unchanged fencing token.
- Restored the single-changed-path exemption so a tiny edit cannot cross over into a full resolution.
- Normalized Windows report paths, restored real Windows maintenance-test execution, and made the Windows CI store-resolution gate serial and feature-enabled.
- Prepared 2.33.2 versions, release notes, finding, docs map, and release workflow evidence.

## WHY

Live Miller evidence showed a single-file change triggering a 182,867 ms full resolution over 549,149 rows. Windows crash-contract runs also intermittently failed with SQLite locking protocol or immediate publication-fence loss. Earlier verification had both a zero-test false green and a parallel-overload false failure.

## HOW

Retries are narrowly limited to SQLite code 15 on read-only operations and wrap the first lazy query/pragma, not only `Connection::open`. Writer and lease mutation paths remain unretried. Deterministic logical-time APIs remain for contracts; production uses wall-time APIs sampled inside the acquired transaction. The scope planner now short-circuits crossover for at most one changed path.

## IMPACT

The corrected source candidate is release-ready. Exact-tree verification passed: default suite in 96.6s; full contract suite in 713.2s; feature-enabled serial resolution target 24/24 in 101.54s; strict workspace all-target/all-feature Clippy with `-D warnings`; formatter; xtask tests; release preflight for 4 targets/32 inputs; package manifest; and `git diff --check`. Publication and asset verification are the next milestone.
