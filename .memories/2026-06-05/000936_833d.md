## Expanded source-region support across the language matrix

- **WHAT:** Added shared source-region collection configs for every supported `julie-extractors` language with parser-backed comment, string-literal, or embedded-region syntax. Added a comprehensive extraction-surface test covering 35 of 36 languages, with `regex` explicitly treated as domain-limited for this source-region contract.
- **WHY:** `v2.1.0` shipped the `source_regions` artifact contract but only populated a narrow first slice. Miller exposed that C# repos got no `source_regions`, making the region-text index empty despite the 36-language product claim.
- **HOW:** Kept the behavior centralized in `crates/julie-extractors/src/base/source_regions.rs`, reused `LanguageSpec::is_doc_comment` instead of a second hard-coded doc-comment table, added filtered support for generic quoted string nodes and Markdown HTML comments, and added embedded metadata for Razor C# blocks plus Markdown fenced code blocks.
- **IMPACT:** Miller now receives C# `source_regions` rows; the focused test prevents future supported languages from being silently skipped unless explicitly domain-limited.
