Rewriting the published tag would be unsafe, so the clean path is a follow-up patch release.
- **HOW:** Kept emitted React route fact behavior unchanged while grouping helper inputs into `ReactRouteDefinitionFact`. The `v2.5.7` notes retain the framework route facts from `v2.5.6` and explicitly mention the clippy fix.
- **IMPACT:** The corrected release prep now passes the CI clippy gate locally and is ready to commit, push, and publish as `v2.5.7`.
