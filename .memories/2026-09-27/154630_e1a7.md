## WHAT
Canonical receiver enrichment will run at `registry::extract_for_language_at`; the CLI will only serialize receiver facts.

## WHY
The CLI's ASCII backward scanner misses Unicode and language-specific syntax, guesses partial expression receivers, and can mislabel CSS selectors. Public extraction APIs currently lack those CLI-only facts.

## HOW
Use bounded AST lookup with explicit grammar handling, authoritative receiver/qualifier pairs and null suppression. Enrich embedded code before remapping. Skip the outer Vue pass because Vue reparses scripts/template expressions through the inner registry and then relabels their identifiers. Keep receiver types and spans unchanged. A registry-gated all-language matrix checks canonical and SQLite output.

## IMPACT
Implementation is in progress in the receiver-facts worktree. Reporting measurement uses an immutable baseline and fixed 14/1315-file artifacts; no count optimization is justified yet.
