## Added JSONL Artifact Exporter

### WHAT
Implemented SQLite v1 to JSONL v1 export in `crates/julie-extract-artifact` and wired JSONL/report artifact contract tests into the `cargo xtask test contract` tier.

### WHY
Task 8 requires deterministic JSONL snapshot export from canonical SQLite artifact rows. JSONL is the secondary product output, so it needs contract tests and named-tier coverage instead of relying on ad hoc worker commands.

### HOW
- Added `jsonl` module with ordered snapshot export, envelope writing, metadata projection, JSON text decoding, deterministic row ordering, and atomic path export through a temp file.
- Added contract tests for record order, envelope shape, every JSONL record kind, JSON text decoding, deterministic output, and failed path export behavior.
- Updated `xtask` contract tier so `schema_contract`, `report_contract`, and `jsonl_contract` all run under the public contract gate.

### IMPACT
Task 8 behavior is implemented and verified. The contract tier now protects all artifact-facing contracts currently present, reducing drift risk before CLI export work begins.
