## Fixed all 27 findings from the high-effort HTTP-client code review

A workflow-backed high-effort review of the 10 unpushed HTTP-client commits (origin/main..HEAD) surfaced 27 verified findings: 5 false-positive paths violating the M2 rule, 5 recall losses, a capabilities-contract gap, and cleanups. All fixed TDD-style (13 new tests in `src/tests/http_client/mod.rs`, each watched failing first).

### WHAT
- **kotlin.rs**: ktor now requires lowercase verb methods (uppercase DSL calls like `queue.DELETE(...)` no longer emit); Spring receiver proof anchors both edges of the declared param type (RestTemplateRegistry/WebClientFactory/WebClient.Builder no longer prove); OkHttp root detection dropped the `contains("Request")` fallback (exact `Request` identifier only); `annotation_name` returns the trailing identifier so `@retrofit2.http.GET` resolves; dead `okhttp3.Request.Builder` gate arm removed; gates bundled into `KotlinGates`.
- **php.rs**: Symfony receiver proof now checks the declared parameter type AST (was whole-body substring scan); import gates rebuilt as single-pass `ImportGates` over `namespace_use_declaration` + `qualified_name` nodes (restores FQN-only Guzzle recall, keeps comment immunity, 1 walk instead of 5); curl collection now covers top-level script code via `collect_curl_in_scope(root)` with gather skipping nested function scopes; handle reassignment flushes the previous handle (both requests emit); no-op url_start/url_end reassignments removed.
- **elixir.rs**: httpc arm requires the `:httpc` atom receiver (bare `httpc` variables silent); unreachable nested if collapsed; verb table delegates to shared helper.
- **rust.rs**: `has_rust_use_crate` reads the `use_declaration` `argument` field so `pub use hyper::...` proves the import; verb tables replaced by shared helpers; gates bundled into `RustGates`.
- **http_clients/mod.rs**: new shared `verb_for_lower_method` (exact lowercase, fluent APIs) and `verb_for_token` (case-tolerant, attested literals/enums) — single source of truth for all five collectors.
- **structural_fact_registry**: frontend contract test now derives pattern ids from `framework::frontend_specs()` instead of a hardcoded two-element list.
- **capabilities.json**: re-added `rust.http_client.instance_receiver` open_gaps entry (struct-field `self.client.get(...)` still silent by M2 — the residual the deleted deferred entry documented).

### WHY
The review confirmed the hardening commits shipped known-broken: e.g. `import io.ktor.client` + `queue.DELETE("/jobs/1")` emitted a false client fact, and `pub use hyper::Request;` never gated hyper chains. M2 rule: a false positive is worse than a miss; deleted open_gaps entries also hid real residual misses from the capability contract.
