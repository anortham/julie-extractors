## Test-detection precision plan ready

The approved precision-first direction is now captured as a design and light implementation plan in the isolated worktree.

- **WHAT:** Added `docs/plans/2026-08-19-test-detection-precision-hardening-design.md` and its implementation plan.
- **WHY:** Scala and Elixir currently classify every callable in conventional test paths; Python accepts every `pytest*` / `unittest*` decorator. These rules can publish helpers, fixtures, and mocks as runnable tests.
- **HOW:** Preserve the existing `is_test_symbol` interface. Remove path-only callable positives for Scala/Elixir; accept only `pytest.mark.*` and explicit unittest skip/expected-failure decorators; prove fixture/mock negatives and existing positives with strict TDD.
- **IMPACT:** One serialized Luna task can fix the behavior without schema, capability, or module-boundary changes. The full default baseline is green in the worktree.
