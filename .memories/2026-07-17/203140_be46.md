## Closed HTTP parity open_gaps: symfony.route.v1 + ktor.route.v1

### WHAT
Fixture-backed collectors for PHP Symfony `#[Route]` and Kotlin Ktor server routing; moved both from open_gaps → supported.

### WHY
Close documented HTTP-boundary deferrals with restricted, static-literal gates.

### HOW
- **Symfony:** separate pattern id; Spring-like metadata (`attribute_kind`, class prefix join); import gate `Symfony\\Component\\Routing\\`; M2 via `static_route_arg` Php
- **Ktor:** design §4.6 restricted gate (bare verb + trailing lambda + static arg0 + lexical `routing{}`/`route{}`); no nested `route()` prefix join; import gate `io.ktor`

### IMPACT
Verification green: unit tests, language xtasks, golden, capability, `silent_cells=0` / `quality_bar_debts=0`. Intentional remaining open_gaps: php.http_client.deferred, laravel.route_service_provider_prefix, kotlin.functional_routing, kotlin.http_client.deferred.
