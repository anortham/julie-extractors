## Fixed reference-resolution branch review findings

### WHAT
- Added full and delta rechecks for already-resolved pending relationships and generic identifier overlays before fill/propagation.
- Added artifact-store worklists for all resolved pending rows and all resolved identifier rows.
- Made tier-2 import resolution require a resolved source module when import metadata includes `source`.
- Aggregated `resolution_report` rows across pending and identifier overlays by `(language, tier, outcome)`.
- Added regression fixtures/tests for stale incremental overlays, unresolved-source aliased imports, and duplicate report rows.

### WHY
The review found three real risks: stale resolved overlays could survive when an unchanged caller file became ambiguous after an incremental scan; TypeScript aliases from missing modules could resolve to unrelated workspace symbols; and report output could emit duplicate by-language rows for the same bucket.

### HOW
- Shared recheck helpers demote stale pending overlays and co-located identifier overlays, or re-record generic identifiers with current outcomes.
- `load_import_records` now reads import `source`, resolves relative module paths against `files.path`, and records `source` on `ImportRecord`.
- Tier 2 now treats `(source present, module_file_id missing)` as unsafe instead of matching any same-name candidate.
- The report query wraps the `UNION ALL` in an outer `GROUP BY` with `SUM(cnt)`.

### IMPACT
The branch no longer preserves stale reference-resolution rows across normal incremental scans, avoids unsafe aliased-import false positives, and emits one stable report row per language/tier/outcome bucket.
