## Task 3 complete: TS export-aware visibility + static method signatures

### WHAT
TypeScript extractor now marks exported type-name declarations as `Visibility::Public` and prepends standalone `static` to static method signatures.

### WHY
Cross-file static-tier resolution requires storage visibility `"public"`. Non-exported TS classes correctly stay `None` so cross-file static refuses them.

### HOW
- `is_exported_declaration`: parent kind == `export_statement` (covers export default)
- `extract_ts_visibility`: accessibility_modifier wins; else exported → Public; else None
- Wired on interface/enum/type-alias (class/function already called the helper)
- Method signature: `static ` prefix when `has_modifier(static)`
- Tests + TS/TSX goldens (31 null→Public)
