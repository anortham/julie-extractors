## HOW

Spot checks also confirmed pending-call creation lives in per-language relationship modules absent from several task file lists. Additional review found a Scala primary-constructor parent exception, stale QML visibility work, a Python symbol-ID wording error, and insufficient negative evidence for same-file constructor inference.
