## Bounded cross-key from-artifact retries

Byte-identical `store import --from-artifact` requests with new request/idempotency keys no longer replay every artifact file before learning the manifest is reusable.

- **Root cause:** Same-key coordinator replay returned early, but cross-key retries always entered `execute_from_artifact`, loaded each artifact file, and wrote L1/L2/L3 before `ManifestStore` reported `Reused`.
- **Fix:** Fresh preflight must match the current exact manifest's terminal originating request by byte-identical payload. A private generation/hash hint is then transactionally rechecked after source SHA/metadata verification in the first quantum.
- **Safety:** Changed artifact payloads and exact-store origins whose coordinator request is incomplete receive no hint and execute the normal materialization path.
- **Telemetry:** Fast retries complete with durable terminal event `store_from_artifact_reused`; the regression asserts zero `store_from_artifact_versions_written` events.
