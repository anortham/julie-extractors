- **BLOCKER — module shadowing fix is incomplete (codex found, I confirmed by test).** `files_importing_names` requires a touched symbol name matching the import binding. When the shadowing file's exports are **disjoint** from the import, the importer never enters delta scope. Existing test masks it by defining `helper` in BOTH modules.
  - Add `src/util.ts` exporting only `unrelated` over `src/util/index.ts` exporting `helper`, consumer does `import { helper as h } from './util'` → delta keeps `h` resolved to `util/index.ts::helper`; full pass says `missing`. **Stale wrong answer.**
  - Symmetric: `delete` of a disjoint shadow file → delta says `missing`, full says resolved. Also wrong.
  - Same-name shadow delete DOES pass (pre-delete `touched_symbol_names` collection covers it).
- **CONFIRMED — SQLite bind-limit regression introduced by this branch.** `unresolved_pending_in_files` (resolution.rs:2480) builds ONE unchunked `IN (...)`; branch changed its input from `changed_file_ids` (1 file) to widened `ownership_files`.
