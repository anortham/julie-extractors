## Fixed: deltas no longer compute the workspace-wide resolution_report — gate green at 51 ms

**WHAT:** `ResolutionReport::rows` is now `Option<Vec<ResolutionReportRow>>`, computed only when the pass re-derived the whole workspace (`effective_full`: full scan, v3 backfill, crossover-promoted delta). Scoped passes — single-file updates AND Step B's scoped whole-repo scans — return `None`, and the JSON report section renders `totals`/`origin_totals`/`by_language` as `null` ("not recomputed", never "zero"). Contract documented in `docs/contracts/reports.md`.

**WHY:** The bisected root cause of the 82→180 ms delta-gate regression: the O(workspace) report aggregate ran inside every resolve pass, inside the write transaction, on every Miller converge save.

**HOW (TDD):** RED — new `resolution_report_scope.rs` (3 in-process tests: full carries rows, scoped delta skips, promoted delta carries) + 2 section-rendering tests in `reports::tests` pinning null-vs-empty. GREEN — `run_resolution` computes rows iff `effective_full`; section renders nulls via an `aggregates` closure; failed-arm output byte-identical (empty-rows aggregates == old zeroed literals).

**Key design call:** uniform rule "aggregates iff pass re-derived the workspace", NOT `corpus_current` — whole-corpus scoped scans also skip, keeping ONE measured crossover curve for every scoped pass. The sweep (whole_corpus scopes) then measured the crossing at ~80% (0.96x at 70%, 1.08x at 80%), so `DELTA_SCOPE_CROSSOVER` moved 0.6 → 0.7 under the same one-sided budgets-move-to-measurement rule.

**IMPACT:** `single_file_delta_is_within_budget` GREEN at 51-52 ms (was 180 red; 150 ms ceiling untouched, 100 ms design target met with 2× headroom). Production single-file updates shed the O(workspace) in-tx cost that extrapolated to seconds at dotnet/runtime scale. Stale ~81 ms harness notes replaced with 2026-08-05 numbers.

**Verified:** perf suite release 5/5 (sweep asserts 0.7 ≤ measured crossing), fmt clean, clippy -D warnings clean, xtask default/contract/capability all exit 0.
