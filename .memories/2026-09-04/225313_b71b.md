## Audit Wave 4: Dead Code, Duplication, and API Narrowing Complete & Merged

All 8 tasks implemented, verified, reviewed with Codex (`gpt-6-astra`), and merged into `main` (PR #17).

### Completed Work
- **Task 1**: CLI binary turned into a 3-line shim over `julie_extract_cli::run_from_env()`, eliminating duplicate compilation across `main.rs` and `lib.rs` and allowing removal of `#[allow(dead_code)]`.
- **Task 2**: Removed obsolete orchestration layer (`ExtractorManager`, `routing_symbols.rs`, `routing_identifiers.rs`, `routing_relationships.rs`), routing extraction directly through canonical entry points.
- **Task 3**: Extracted shared doc-comment handling (`previous_comment_texts`, `select_doc_comment_block`) and modifier visibility parsing (`visibility_from_modifiers`) into `base::visibility` and `base::extractor`.
- **Task 4**: Created `ParsedVueSfc` in `vue::parsing` ensuring each SFC script section is parsed once and shared across symbols, script-setup, identifiers, relationships, test calls, and complexity metrics.
- **Task 5**: Narrowed `julie-extractors` public API surface; internalized 38 language modules to `pub(crate)` and exposed curated root exports. Documented removals in `docs/contracts/extraction-output-changes.md`.
- **Task 6**: Narrowed `julie-extract-artifact::store` public surface to actively imported symbols and test-gated statement preparation metrics.
- **Task 7**: Consolidated duplicate store CLI helpers (`quote_identifier`, `valid_blake3_hash`, `valid_root_relative_path`, `base_report`, `open_cli_coordinator`) into `store::common`.
- **Task 8**: Merged `test_utils.rs` into `tests/helpers.rs` and deduplicated identical test helper implementations.
- **Codex Review Remediations**:
  - Restored proper modifier handling in Swift vs Kotlin/Scala (preventing `open` from being treated as public visibility in Kotlin/Scala).
  - Ensured Vue SFC complexity metric extraction passes the pre-parsed tree to avoid re-parsing script blocks.
  - Re-exported public constituent types in `julie-extract-artifact::store` for caller nameability.
