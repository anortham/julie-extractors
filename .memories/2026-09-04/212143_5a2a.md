## Audit Wave 3: Query and Loop Fixes Completed and Merged

### WHAT
Implemented all 11 tasks from `docs/plans/2026-09-04-audit-3-query-and-loop-fixes.md` across 4 batches, completed non-interactive Codex external review, addressed all findings, and merged PR #16 (`1f21a19b`) to `main`.

- **Batch A (Tasks 1–4)**:
  - Task 1 (C3): Keyset paging with `(k1, k2)` row-values in `copy_table` SQLite bulk copies.
  - Task 2 (C5): Deduplicated structural facts per file using `HashSet<&str>`.
  - Task 3 (C9): Avoided allocations in `StoreFileVersion::try_from_artifact_file` by passing string by value.
  - Task 4 (E6): Reused connection in `LeaseHeartbeatGuard` rather than reconnecting per tick.
- **Batch B (Tasks 5–6)**:
  - Task 5 (A6): Added one-time migration marker `resolution_retired = '1'` in `store_meta` on first writer open.
  - Task 6 (A11): Deferred `PRAGMA wal_checkpoint(TRUNCATE)` to writer `close()` / `Drop`.
- **Batch C (Tasks 7–9)**:
  - Task 7 (E7): Pre-detected language carried on `SupportedTarget` to avoid redundant detection.
  - Task 8 (A7): Confined file row attribution `GROUP BY` to JSON scan mode only.
  - Task 9 (A3/A4): Implemented bounded `SnapshotCache` with generation tracking, LRU queue compaction, and mtime/size checks to guarantee a single disk read per file across passes.
- **Batch D (Tasks 10–11)**:
  - Task 10 (A5): Allowed `BaseExtractor::new` to accept pre-normalized relative paths without redundant `canonicalize`.
  - Task 11 (C1): Reused tree-sitter parse `Tree` from header disambiguation in `pipeline.rs`.

### WHY
Remediated query and loop inefficiencies identified in the audit without introducing schema bumps, contract changes, or fixture drift.

### HOW
- Executed tasks in isolated worktree `.worktrees/audit-3-query-and-loop-fixes`.
- Validated each task with targeted unit/language/golden tests and whole default suite.

- Merged via PR #16 with clean rebase to `main`.

### IMPACT
- Keyset paging avoids `OFFSET` scanning penalties on large tables.
- Deferred TRUNCATE prevents hot-loop fsync delays during incremental ingestion.
- Snapshot cache eliminates duplicate disk I/O between language detection and extraction.
- Default test suite clock remains under 100s warm (71–98s).
