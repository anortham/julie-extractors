## Completed Vue/Razor annotation implementation slice

- **WHAT:** Closed the remaining Vue and Razor annotation capability gaps with real extractor behavior, focused tests, fixture evidence, and capability matrix updates.
- **WHY:** Annotation coverage was the final non-structural annotation debt after prior language slices. The project goal is rich, fixture-proven language data quality across the full supported set, not skeleton capability claims.
- **HOW:** Delegated the first pass to Cursor Agent, then reviewed and sent a targeted fix loop. Vue now attaches `defineOptions`/`defineProps`/`defineEmits` metadata to the Vue SFC component symbol and `defineExpose` to referenced function symbols, with guards so CSS class symbols and macro call symbols are not falsely annotated. Razor now normalizes embedded C# attributes into symbol annotations for class, method, and property declarations using C# annotation syntax rules.
- **IMPACT:** `vue.annotations` and `razor.annotations` open gaps are closed. Scorecard annotation fixture coverage is now 23/36 and quality-bar debts are down to 25, all remaining debts are structural-facts/source-region related.
