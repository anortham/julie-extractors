## Added JVM and mobile code structural facts

The structural-facts campaign now covers Java, Kotlin, Scala, Swift, Dart, and VB.NET with fixture-backed semantic facts.

- **WHAT:** Added `collect_code_structural_facts`, wired it into extraction, registered capability-matrix pattern IDs, added per-language structural-fact tests, expanded golden fixtures, and updated the findings scorecard.
- **WHY:** These languages had explicit Task 10 structural-facts open gaps. The project goal is product-grade tree-sitter coverage across languages, not skeleton support.
- **HOW:** Implemented versioned facts for Java synchronization/resources/lambdas/annotations, Kotlin suspend/delegates/annotations, Scala extensions/givens/for comprehensions/annotations, Swift await/actors/attributes, Dart await/async/annotations, and VB.NET handles/implements/events/attributes. Review fixes added Java parameterized annotation support, corrected Scala extension receiver and given metadata, and normalized VB.NET attribute/handles metadata.
- **IMPACT:** Strict language quality now reports `structural_facts` at 26/36 and `quality_bar_debts` at 10, with remaining structural-facts debt limited to zig, php, ruby, elixir, lua, qml, r, bash, powershell, and gdscript.
