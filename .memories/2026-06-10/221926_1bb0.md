## Closed Ruby relationship and QML type native debts

The native-debt implementation slice removed the remaining real debts in the already-audited `relationships` and `types` domains.

- **WHAT:** QML canonical extraction now emits product `TypeInfo` rows through `extract_qml`; Ruby relationship extraction now resolves bare same-parent method calls even when an import symbol shares the target name.

- **HOW:** Added QML fixture-backed type assertions and golden rows, updated QML capabilities to `types: true`, added Ruby canonical relationship tests for `run -> helper`, and removed Ruby/QML from `DOMAIN_APPLICABILITY.native_debt` after verification.
- **IMPACT:** `relationships` is now applicability-complete at 36/36 and `types` is now applicability-complete at 29/29, with remaining type gaps classified as `not_applicable` or `convention_only` rather than native debt.
