## Added CSS and Vue structural facts

### WHAT

Implemented a focused web structural-facts extractor and wired it into canonical extraction.

- CSS now emits versioned structural facts for selector rules, custom properties, media queries, and keyframes.
- Vue now emits versioned structural facts for SFC sections and template directives, including directive arguments/modifiers/shorthand metadata.
- Added CSS/Vue unit tests, regenerated golden fixtures, and updated `capabilities.json` plus the language coverage review scorecard.

### WHY

CSS and Vue had real structural data available from their syntax but were still marked as open structural-facts gaps. The quality goal is to raise language support uniformly, not merely keep the current high-coverage languages strong.

### HOW

Added `base::web_structural_facts` and integrated it after generic/framework structural facts in the registry. CSS facts come from tree-sitter node walks. Vue SFC section facts use the existing SFC parsing model, while template directive facts scan template attributes and attach to the containing component symbol. Vue component spans were widened to EOF so file-level component containment works for section facts.

### IMPACT

The strict scorecard now reports `structural_facts` at 14/36 and `quality_bar_debts` at 23. CSS and Vue are no longer structural-facts debts; remaining work is 22 structural-facts gaps plus regex `source_regions`.
