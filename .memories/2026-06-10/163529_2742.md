## Completed remaining annotation capability audit

### WHAT

Used the Cursor Agent workflow to finish the remaining annotation-domain audit slice and then reviewed the resulting diff before committing.

- TSX now has fixture-proven class decorator annotation evidence via `@Component()` on `WorkerModel` in the basic fixture.
- JSX now has fixture-proven class decorator annotation evidence via `@registered` on `WorkerModel` in the basic fixture.
- The capability matrix no longer has generic `attribute_or_decorator` annotation gaps for the remaining 19 languages.
- Go, Zig, Vue, and Razor retain concrete implementation gaps for annotation-like metadata that should be implemented later.
- HTML, CSS, Ruby, Lua, QML, R, Bash, SQL, Regex, Markdown, JSON, TOML, and YAML are explicitly classified as annotation `not_applicable` for their observed symbol kinds.

### WHY

The project quality goal is to raise every language to a high extractor data-quality bar, not to hide missing behavior behind generic placeholders. Annotation coverage needed the same treatment as earlier literal, complexity, doc comment, and structural evidence slices: either fixture-backed support, explicit true non-applicability, or concrete product debt.

### HOW

Cursor generated the first pass under a bounded prompt. Codex reviewed the diff, normalized accidental JSON punctuation escape churn back to the existing file style, checked the fixture annotation rows directly, and ran the project gates instead of relying on Cursor's report.

### IMPACT

- `annotations` fixture-proven support improved from 17/36 to 19/36.
- `quality_bar_debts` dropped from 45 to 38.
- `silent_cells` remains 0.
- Remaining annotation work is now focused on four real implementation slices: Go struct tags/directives, Zig declaration metadata, Vue script/component metadata, and Razor embedded C# attributes.
