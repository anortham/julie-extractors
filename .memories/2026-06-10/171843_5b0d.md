## Completed Go/Zig annotation implementation slice

### WHAT

Used Cursor Agent as the implementation worker for a bounded Go/Zig annotation slice, reviewed the diff, sent one fix loop, verified independently, and prepared the slice for commit.

- Go now emits annotation markers for struct field tags on field symbols.
- Go struct symbols now emit a `field_tags` summary annotation when contained fields have struct tags.
- Go functions/methods now emit annotation markers for `//go:` compiler directives without treating those directives as `doc_comment`.
- Zig functions now emit declaration metadata annotations for `inline` and `export`.
- Zig variables/constants now emit declaration metadata annotations for `threadlocal` and related helper-supported declaration metadata.
- Capability rows close Go `struct`/`field`/`function` annotation gaps and Zig `function`/`variable` annotation gaps.

### WHY

After closing doc-comment coverage, remaining annotation debt was concentrated in Go, Zig, Vue, and Razor. Go and Zig were the safest bounded implementation pair because both gaps map to declaration-local tree-sitter metadata and can be proven through basic golden fixtures and focused language tests.

### HOW

Cursor implemented the first pass. Codex found a blocker where `//go:noinline` was also being recorded as `doc_comment`; a focused Cursor fix loop introduced filtered Go function doc-comment handling and updated tests/goldens so compiler directives are annotations only.

### IMPACT

- `annotations` fixture-proven support increased to 21/36.
- `quality_bar_debts` dropped from 29 to 27.
- Remaining annotation open gaps are now only Vue and Razor.
- `silent_cells` remains 0.
