## Added SQL structural facts coverage

The SQL language slice now has first-class structural facts instead of relying on skeleton coverage.

- **WHAT:** Added `collect_sql_structural_facts`, wired SQL facts into extraction, registered SQL structural capability patterns, expanded SQL golden fixtures, and added focused SQL structural fact tests.
- **WHY:** The language data quality plan is raising extractor quality across all supported languages; SQL needed semantic table/query/schema facts rather than just syntax-level extraction.
- **HOW:** Cursor implemented the SQL slice, then review fixes tightened the contract: `sql.constraint.v1` is advertised, view source tables are scoped to the view query instead of including the view itself, and select-query metadata counts local projections/sources/where clauses accurately.
- **IMPACT:** SQL now contributes table, column, constraint, foreign key, index, view, trigger, CTE, select, join, update, and transaction facts. The scorecard moves structural facts to 20/36 languages and leaves 16 structural-facts languages plus the remaining quality-bar debt.
