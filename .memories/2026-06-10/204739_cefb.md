## Closed structural-facts debt across all supported languages

- **WHAT** - Added parser-backed structural facts for the final five debt languages: Zig, QML, Bash, PowerShell, and GDScript.
- **WHY** - The language data quality plan required structural facts to be semantic and fixture-proven across the full supported language set, not concentrated in only a few strong languages.
- **HOW** - Used Cursor Agent for the implementation, then reviewed and sent a fix loop for bash doc-comment collateral and Zig builtin coverage. Added per-language structural fact tests, updated goldens, updated capabilities, and documented the Phase 11 scorecard.
- **IMPACT** - `node scripts/language-data-quality-report.mjs --strict` now reports `silent_cells: 0`, `quality_bar_debts: 0`, and `structural_facts: 36/36`.

Review fixes before commit:

- Bash `export APP_ENV` was moved away from the shebang so it no longer receives `#!/usr/bin/env bash` as a doc comment.
- Bash doc-comment capability support was restored to the pre-slice `function`/`import` evidence shape.
- Zig builtin coverage now asserts `@import`, `@This`, and `@sqrt` as normalized `builtin_name` values without ordinary function-call false positives.
