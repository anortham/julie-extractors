## Full project review of julie-extractors (post-v2.2.1)

Ran a 4-agent fan-out review (extractors, architecture/contracts, performance/robustness, tests/CI/release) plus direct verification of high-severity claims.

### Verified problems
- **MSRV gap (verified locally):** workspace builds fail on rustc 1.90.0 — libsqlite3-sys 0.38.0 build script uses unstable `cfg_select!`. No `rust-version` in workspace Cargo.toml; CI on `stable` masks it.
- **Stale workflow defaults:** release-binaries.yml:9 and specialist-gates.yml:9 default to `2.1.0` (current 2.2.1).
- **No cargo caching in ci.yml.**
- **Parsers recreated per file** (pipeline.rs:109-126, `Parser::new()` + `set_language` per file) — thread-local reuse is a cold-scan opportunity; measure first.
- **75 `Regex::new` sites in extractors**, some compiled per call in hot paths (e.g., javascript/mod.rs:634-647 recompiles on every doc comment) — should be LazyLock.
- **dart/mod.rs:147** `node.parent().unwrap()` in extraction walk (mitigated product-wide by catch_unwind → FailedPreserved rows).
- **commands.rs 3,228 lines / writer.rs 2,419 lines** god modules; registry.rs ~620 lines of copy-paste extractor wiring.
- **Schema version redundancy:** `schema_version` + `sqlite_schema_version` both =3; docs/contracts/cli.md says contract v2 while code enforces v3.
- **Identifier coverage 23/34 languages** (bash/json/yaml/toml/markdown/qml weaker); unbounded recursion in walk_tree (no depth guard); grammar version skew + 4 fork deps (qmljs, razor, powershell, vb-dotnet).

### Refuted agent claims (do not re-report)
- `captures[1]` "panic risk" in js/python/razor/gdscript: regex groups are non-optional, cannot panic when match succeeds. Real issue is per-call compilation, not panics.
- span.rs byte-length columns: consistent with tree-sitter's byte-column convention on both code paths; a documentation issue at most.

### Strengths confirmed
catch_unwind per-file isolation, blake3 content-hash incremental, single-transaction WAL writes, spool-to-disk memory bounding, atomic JSONL rename, data-loss guard, 90s wall-clock tripwire + convention tests + per-language xtask commands all real.
