## Removed quadratic scans from the new call-initializer inference code

**WHAT:** The new per-language inference code slowed some languages on long files. I fixed seven of them:
- **C++:** the index build called `parent()` for every node. `same_file_defines_type` walked the whole file once per `auto` local. Class names are now indexed in `ReturnTypeIndex.type_names`.
- **C#:** the index build now carries the innermost type and member down its stack (`Surroundings`). Before, each parameter and local walked up the tree.
- **Go:** `declared_names` now carries the parent and grandparent on its stack.
- **Lua:** `scope::LocalBindings` caches the declared names of each scope node. Before, each call scanned every earlier sibling. `declares_local` no longer allocates.
- **Ruby:** `ModuleBody` reads each module body once to answer `is_module_function`. `collect` carries the lexical owner down and caches `definition_scope` per `def`.
- **JavaScript:** `is_later_declarator` is now one forward scan with a cursor, and it runs only for nodes that have a symbol.

**WHY:** tree-sitter `Node::parent()` walks down from the root and scans siblings at each level. A `parent()` call for every node is therefore quadratic in the number of top-level declarations or class members. `prev_named_sibling` also calls `parent()`.

**HOW I verified:**
- Output is byte-identical to HEAD `3ae9ba3a` on 15 corpus repos and 25 language folders. Only the `indexed_at` and revision metadata differ.
- I benchmarked against `main` built with the same local rustc 1.97.1. The 3.5.0 binary in code-kb was built with a different rustc and is about 20% faster, so it is not a fair baseline.
- Results against `main`: radzen +1.8%, miller +0.3%, nlohmann −3%, and the other repos within about ±1–4%.
- Long single files: C++ −10%, Erlang −37%, Zig −26%. Lua and Ruby are +6% (they were +34% and +24%). JavaScript is even (was +8.5%). TypeScript, Swift and Kotlin are +3–4%.
- clippy, the default tier (37 s) and the contract tier pass.

**Profiling notes:**
- samply needs `perf_event_paranoid` of 1 or lower, and changing it needs sudo.
- `eu-stack -p PID -i` works (ptrace_scope is 0). Do not pass `-q`, because it turns off symbol names.
- Scripts are in `~/.cache/julie-type-infer-scratch/perf/`: `sample.sh`, `build-fix.sh`, `bench-langs.sh`, `cmp2.sh`.
