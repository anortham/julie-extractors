## Elixir call-initializer inference: review fixes

- **Do-block arity:** `call_arity` counts a trailing `do_block` as one argument, so `with_lock do ... end` reaches `with_lock/1`.
- **Remote spec names:** a call on another module qualifies the spec return in the callee scope (`t` -> `Shop.Store.t` only when the callee declares `@type t`; leading alias expands). The name must read the same in the caller, or nothing is recorded.
- **Quote blocks:** `SpecKey` now carries the enclosing `quote` start byte, so quoted specs match only quoted defs. Quoted defs are excluded from `CallScope::definitions`.
- **Lexical aliases:** `CallScope.aliases` is a source-ordered list of `LexicalAlias` with a byte range (directive start to end of the innermost do_block / stab_clause / keyword def). Latest covering alias wins.
- **Golden change:** `module_calls` line 36 `Entry.make()` before the nested `defmodule Entry` is now pending. Elixir's `defmodule` macro emits the alias (`require ..., as:`) at the defmodule position (kernel.ex), so earlier code does not see it.
- **Corpus:** ecto/plug/phoenix/phoenix_live_view: no fact or edge change prev -> fix; 7 new facts vs baseline, all correct. plug is 34 -> 35 (not 29 -> 30).
