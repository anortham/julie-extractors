## Scala call-initializer inference: fixed the review findings

- **What:** I fixed five review findings in `crates/julie-extractors/src/scala/type_facts.rs`.
  - A class, object, or trait that can inherit (it has an extends clause, a self type, is a case class, or is an anonymous, enum, or given body) no longer trusts its own defs. This covers bare `load()`, `this.load()`, and `Repo.create()`, because an inherited overload can be the one the call selects.
  - `for` enumerator patterns (the generator `<-` and value `=` forms, in paren, brace, and yield shapes) now shadow outer defs. The old code read `child_by_field_name("enumerators")`, which returned the `(`/`{` token.
  - A named `given` now shadows an outer def.
  - `.get` does not unwrap when the file declares its own class, trait, enum, or type alias named Option, Some, Try, or Success. A new index set holds these names.
  - A companion object that can inherit `apply` records no fact for `Name(..)`.
- **Tests:** I added 5 regression tests. The anonymous `this.make()` case changed from positive to negative, because an anonymous class always inherits.
- **Corpus:** The corpus has 753 files. The slice now adds 54 new facts, down from 178. Every current fact belongs to the set I already checked. The 124 dropped facts came from templates that can inherit.
- **Verification:** All of these pass: the language, default (32s), and contract tiers, clippy, the fmt check, and the strict quality report.
