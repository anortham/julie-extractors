## The all-language type inference workflow crashed the machine (out of memory); resumed

**WHAT:** The first workflow run (wf_4d0c483c-7ce) started 16 implement agents at once, each in its own worktree. Their parallel cargo builds and tests used up the 62 GB of memory and the machine crashed hard. No agent had finished or committed.

**State after the crash:**
- 16 worktrees under `.claude/worktrees/wf_4d0c483c-7ce-N` hold uncommitted in-progress work on branches `feat/type-infer-<lang>`: csharp, typescript, javascript, python, java, kotlin, swift, go, cpp, c, ruby, php, scala, dart, zig, fsharp.
- Some contain debug files (`zz_dump.rs`, `zz_sexp.rs`, `ast_dump_tmp.rs`) that must be deleted before commit.
- The reboot wiped the scratch dir under /tmp, so the corpus databases are gone.

**HOW (resume):**
- Created worktrees `.claude/worktrees/type-infer-<lang>` for vbnet, lua, r, elixir, erlang, gdscript, powershell.
- Edited the workflow script:
  - No per-agent worktree isolation. Each agent continues in its unit's existing worktree.
  - A semaphore allows at most 5 agents at once.
  - Every cargo command runs with `CARGO_BUILD_JOBS=4 RUST_TEST_THREADS=4`, and no two cargo commands run at once.
- Relaunched as run wf_820b31db-470.

**IMPACT:** When the run finishes, merge the 23 `feat/type-infer-*` branches into `feat/call-initializer-type-facts`, then run the full checks. No push or release.
