## Bounded Task 1 header-only capture

### WHAT

- Split lightweight semantic delta classification from touched-name hydration.
- Missing-state publications now emit fallback before any manifest-delta or symbol-name work.
- Over-bound eligible transitions retain at most 513 lightweight deltas and skip hydration.
- Usable batches reuse one prepared symbol-name statement for at most 512 changes.

### WHY

The prior implementation queried `symbols` once per changed path before deciding to discard all children, defeating the explicit performance reason for header-only first-import and 513+ fallbacks.

### HOW

`capture_resolution_scope_transition` now resolves state first, classifies a bounded private `ScopeChangeDelta` payload only when state exists, and hydrates canonical names only after the bound passes. Typed validation follows the same ordering.

### IMPACT

Corpus-scale fallback transitions avoid unbounded per-path symbol queries while all corrected schema, typed payload, hash, semantic-comparison, and transition behavior stays unchanged.
