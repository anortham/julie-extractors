## Completed recorded-scale replay and default-on incremental resolution

### WHAT

Completed Task 8 with a deterministic faithful Miller-scale A/B replay, the plan-required bulk prior-overlay carry-forward, mode-aware evidence evaluation, default-on scoped resolution, and release/contract documentation.

### WHY

The first recorded-scale scoped run was semantically exact but slower than full because Task 5 still copied about 403k prior rows one-by-one. The feature could not safely become the default until that production bottleneck and the replay oracle's review findings were fixed.

### HOW

- Replaced paged Rust row copying with one transaction containing set-based `INSERT OR IGNORE ... SELECT` from read-only attached store/base databases.
- Revalidates frozen scope, manifests, base metadata/counts/roots, and cumulative delta identity/counts inside the same copy transaction; changed snapshots fail closed.
- Preserves current-version filtering, identifier/pending touched authority, delta replacement precedence, and pending tombstones; coverage includes an older ready base plus newer predecessor delta.
- The evaluator consumes explicit full/scoped mode, fallback, canonical/fixture digests, row diffs, gap/storage, and rebase evidence. Retired throughput/diff fields are labeled report-only instead of vacuously passed.
- Unset `JULIE_STORE_RESOLUTION_DELTA` now selects scoped mode; explicit `off` remains the pre-change forced-full path.
- Updated the deterministic schema-v2 maintenance byte baseline, findings ledger, store contract/docs map, and v2.32.0 release notes.

### IMPACT

Three regenerated recorded-scale runs were row-identical and scoped completed in 18.349–18.675s versus 32.119–32.630s full. A valid 64 MiB+1 accumulated gap payload rebased to a 22-byte empty delta. Scoped resolution is now evidence-backed as the default, with a tested full escape hatch.
