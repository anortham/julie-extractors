## Completed atomic resolution-base rebase and live rotation

### WHAT

Implemented Task 7's fixed-threshold compaction path: exact results crossing 25% semantic replacement/tombstone drift or 64 MiB cumulative canonical gap JSON are promoted to a ready base and atomically bound with an empty delta.

### WHY

Cumulative exact deltas otherwise grow without bound and keep old bases live. Rebase must reuse the already-computed exact scratch, preserve the public base-plus-delta contract, and leave only coherent old or new state under crashes and CAS loss.

### HOW

- Artifact policy validates the bound ready-base file/count/SHA before applying strict thresholds; corrupt catalog metadata fails closed.
- `publish_rebased_exact` fences and CASes the old binding to the validated ready base plus empty delta in one transaction, retires scope, and stores replayable telemetry.
- CLI promotes or reuses the exact manifest base through the existing catalog lifecycle and preserves legacy plus rebase crash boundaries.
- Review added exact 25% and 64 MiB equality/non-equality coverage, canonical JSON gap fixtures, and removed catalog-corruption shortcuts.
