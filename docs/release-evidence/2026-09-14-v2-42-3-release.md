# julie-extract 2.42.3 release verification

Published v2.42.3 release verification.

## Scope

- Removes scan-only source-snapshot retention while preserving cache use for
  store paths.
- Avoids the `symbols` count query unless a file is `FailedPreserved`, retaining
  the data-loss guard for parser and read failures.
- Adds the opt-in `cargo xtask test perf` tier and manual performance workflow.
- Documents the review, test-tier behavior, and canonical release-note pointer.

SQLite schema v7, JSONL v5, report schema v3, family-store schema v2,
extraction contract, identity epoch, parser inventory, fixtures, and external
dependency graph are unchanged.
