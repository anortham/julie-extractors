## Scope

`v2.8.0` finishes the backend HTTP boundary lane with NestJS, Kotlin Spring,
Laravel, Phoenix, axum, and actix route/mount facts; Kotlin, PHP, Elixir, and
Rust `http.client_request.v1` coverage; and the `backend-http-boundary-v2`
contract marker. The final release commit also fixes a review finding where
same-span multi-verb route facts could collapse in persisted SQLite artifacts by
including route template/effective template/verb metadata in route fact identity
hash input.
