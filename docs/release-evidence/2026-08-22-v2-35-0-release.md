## What this release ships

The `store maintain retire-view --view <id>` verb: caller-named, transactional
removal of one dead view's manifest entries, manifests, and `views` row. It
keeps allocator marks, log rows, receipts, and cursors, and leaves the view's
released versions to ordinary GC. Contract text landed in
`docs/contracts/cli.md` and `docs/contracts/store-v1.md`.

Extraction identity epoch is 4, unchanged. Artifact schema 7, JSONL v5,
family-store schema 2, and store format epoch 1 are unchanged.
