### Two gates that were red before this release

`cargo xtask dogfood repo` had been failing since 2.18.0 with `JSONL record N
has unsupported kind reference_site`. `xtask` carried a private duplicate of the
JSONL record allowlist that was never updated when `reference_site` was added;
it now imports `julie_extract_artifact::jsonl::JSONL_RECORD_KINDS`. The nightly
Specialist Gates run `30265418467` shows the failure; the dispatched run above
shows it closed.

`child_row_batch_avoids_per_file_statement_prepare_overhead` asserted
`elapsed < 1750ms` from an ungated default-suite file and failed on shared
runners while passing locally — run `30235449361` failed it at `2.423s` on
`0ceaaae5`, before any v2.19.0 work. The writer's wall-clock budgets live in the
feature-gated `writer_perf.rs` harness; the default-suite file now asserts only
hardware-independent structure, and a new convention test fails if any ungated
file under `crates/julie-extract-artifact/tests/` reaches for `Instant`.

## Independent review

The change was reviewed adversarially across three rounds by Codex and Grok.
Every finding was closed in code rather than recorded as debt:

- Delta invalidation missed receiver-only edits — the worklist now matches on
  `metadata_json.$.receiver` as well as the identifier name.
- Delta ownership was read over changed files only, so a propagated target in an
  unchanged file could be overwritten by the generic chain — ownership is now
  read over the full resolution scope.
- A signature-wide search for `static` matched expression bodies and field
  initializers such as `public int TotalCount => Kinds.Sum(static kind => ...)`
  — the scan is now limited to the modifier prefix, after leading attributes.
  This cost zero bindings on the measured corpus.
- The claimed wrong-edge risk from qualified receivers was measured rather than
  assumed: all 30 qualified bindings were correct workspace references. Chasing
  it surfaced the real defect, which was that
  `file_scoped_namespace_declaration` was never dispatched, leaving the corpus
  with zero namespace symbols and making namespace comparison impossible.

One risk stays open and is recorded in `TODO.md`: an untyped local variable
declaration (`var Fixture = ...`) can shadow a type name invisibly, because
local declarations are not symbols. Parameters are covered. The measured corpus
contains zero instances. It closes with the local-binding slice.
