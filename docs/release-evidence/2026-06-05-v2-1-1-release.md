## Contract Notes

- This patch expands `source_regions` from the initial web/script coverage to
  every supported language with parser-backed comment, string-literal, or
  embedded-language regions.
- Regex remains domain-limited for source regions because the current contract
  has no regex-specific comment, string-literal, or embedded-language region
  kind.
- SQLite schema version remains `2`.
- Artifact integer `extract_contract_version` remains `2`.
- JSONL schema version remains `2`.
- JSON report schema version remains `2`.
- The release packages do not add Julie MCP/server/daemon/search/embedding,
  watcher, dashboard, or editing behavior.
