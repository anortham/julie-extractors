## Tradeoffs And Open Decisions

- The dogfood gate intentionally scans fixtures because fixtures are part of the
  repository extraction surface. Fixtures dominate symbol count and export size.
- The immediate rescan is now hard release evidence: it must return `no_change`,
  write no rows, create no revision, and report unchanged files.
- Repository dogfood timings remain report-only for v0.1.0. A hard threshold
  needs repeated same-machine baseline runs and a release-binary profile.
- This run used the default debug binary. Release-binary performance evidence
  should be captured separately with `--binary target/release/julie-extract`.
- JSONL export remains the dominant runtime and artifact-size cost in this run.
