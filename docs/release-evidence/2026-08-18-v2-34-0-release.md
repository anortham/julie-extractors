## Scope and compatibility

The release retires the resolution write path and fixes manifest language
agreement for content-sniffed `.h` files. It is an intentional break against
v2.33.7: artifact schema 7, JSONL v5, and `store resolve` removed. Family
stores stay schema v2 and migrate in place on first writer open. See
`docs/release-notes/v2.34.0.md` and
`docs/decisions/2026-08-18-resolution-write-path-retirement.md`.
