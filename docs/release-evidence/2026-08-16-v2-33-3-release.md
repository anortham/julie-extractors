## Scope and compatibility

The release bounds incremental resolution around changed state, avoids unnecessary work for unchanged
imports, and hardens cross-platform root identity without changing the public CLI, report, schema, or
store contracts. A cold full index remains expensive; the published performance evidence is for the
incremental path and does not promise fast first-time whole-repository extraction.
