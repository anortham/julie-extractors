# julie-extract 3.2.0 release verification

Published v3.2.0 release verification.

## Scope

- Qt and QML first-class support: nested objects as `field` symbols, inline
  components, signal parameters, pragmas, `required` properties, the reference
  contract (`role`, `receiver`, `change_handler` identifier metadata and the
  `extends` relationship), qmldir `export` rows, and Qt JavaScript directives on
  the scan and check paths. See `docs/release-notes/v3.2.0.md`.
- SQLite schema v7, report schema v3, and the identity epoch (10) are unchanged.
  `EXTRACTION_CONTRACT_VERSION` gains the suffix `qt-qml-v1`.
- The `## 3.2.0` entry in `docs/contracts/extraction-output-changes.md` is
  classified `compatible`; `cargo xtask compat-check` against the published
  3.1.3 binary reported every difference as declared.
