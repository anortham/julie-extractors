# julie-extract 3.1.3 release verification

Published v3.1.3 release verification.

## Scope

- First release with a Linux ARM64 binary, `aarch64-unknown-linux-gnu`, built
  on the native GitHub `ubuntu-24.04-arm` runner, for hosts such as Asahi
  Linux and Snapdragon laptops.
- `cargo xtask release preflight` and `package` accept the new target; the
  workflow contract test requires the new runner and target; `docs/release.md`
  lists six targets.
- The same commit records the v3.1.2 release evidence.
- No extraction change. SQLite schema v7, report schema v3, extraction
  contract, identity epoch, parser inventory, and golden fixtures are
  unchanged.
