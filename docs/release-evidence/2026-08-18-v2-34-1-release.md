## What this release fixes

v2.34.0 wedged every family store written by an earlier binary: the capability
snapshot count check conflicted forever because the 109 `reference_resolution.*`
gap rows were dropped from the snapshot without an epoch bump. Writer open now
reaps those rows; wedged stores self-heal on the next write. Verified end-to-end
against a copy of a wedged production store: the v2.34.0 binary conflicts, this
binary commits and reaps the rows.
