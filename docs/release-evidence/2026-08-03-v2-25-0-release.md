## What shipped

Two-level extraction: `scan --level symbols|full` with immutable per-artifact
level identity (`artifact_metadata.index_level`, absent = full), inherit-or-
usage-error CLI semantics (exit 2 on conflict), the shared registry-dispatch
gate with `strip_to_symbols_level` as the single language-parity authority,
plus two adversarial-review hardenings: the level is established exactly once
inside the write transaction (new `ArtifactWriteError::IndexLevelConflict`
aborts a write racing a concurrent scan's different committed level, and the
non-spooled scan family stamps through the same guard), and an unknown
recorded level fails closed as `schema_incompatible` exit 3 on scan and
update. On the dotnet/runtime yardstick: symbols first build 234 s / 5.47 GiB
vs full 1,422 s / 20.41 GiB (6.1× first serve, identical symbol/file counts);
full-level upgrade rebuild converged to a baseline-identical artifact in
21.7 min while the symbols artifact served. Full notes in
`docs/release-notes/v2.25.0.md`.
