## Contract Notes

- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- File selection precedence is now a documented contract: hard safety
  exclusions, then caller `--ignore-file` rules (decisive), then in-tree
  ignore files with git-exact semantics. See
  `docs/contracts/cli.md` ("File Selection and Ignore Rules") and
  `docs/decisions/2026-06-11-ignore-rule-precedence.md`.
- Report `errors` entries may now describe unreadable in-tree ignore files;
  they are non-fatal.
- The release packages do not add Julie MCP/server/daemon/search/embedding,
  watcher, dashboard, registry, editing, or runtime behavior.
