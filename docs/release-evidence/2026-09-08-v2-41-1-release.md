## Epoch upgrade proof

The published v2.41.0 Linux binary first imported an unchanged Go fixture at
epoch 9. The candidate then imported the identical content hash at epoch 10.
Both immutable file versions remain. The new return-position `Result`
identifier appears at bytes 52-58 only in epoch 10; the constructor occurrence
at bytes 68-74 exists in both. The family advanced to binary 2.41.1 and epoch 10
while preserving its existing `min_reader_version` of 2.41.0.
New families created by the candidate stamp `min_reader_version` 2.41.1;
downstream adoption therefore includes the matching reader-capability update.
The downloaded public Linux binary repeated this proof on a fresh family:
`binary_version`, `min_reader_version`, and `min_writer_version` are 2.41.1,
and `extraction_identity_epoch` is 10.
