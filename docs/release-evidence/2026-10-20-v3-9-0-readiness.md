## Downstream gate

The code-kb candidate built with this exact binary passed its reach gate, its
edit replays, its release corpus check against code-kb 2.7.0 with julie 3.8.0,
and one dogfood round with no open defect. That work found three wrong answers
in this version, all fixed before the tag:

- `api.render = render` wrote a property that duplicated a function (c81388f3,
  then 1f413aa6 for any bare name as the value).
- A chained assignment (`req.get = req.header = function header()`) wrote a
  property that became the parent of the method (683a26d5).
- An assigned property owned the calls in its value, so
  `opts.etag = this.app.enabled('etag')` named `etag`, not the function around
  it, as the caller (683a26d5).
