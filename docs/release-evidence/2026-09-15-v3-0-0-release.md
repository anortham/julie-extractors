# julie-extract 3.0.0 release verification

Published v3.0.0 release verification.

## Scope

- Removes the versioned family store (`store` and every nested verb) and the
  JSONL export (`export`). `code-kb` is the sole consumer and never used them.
- Adds `julie-extract check --path <path> [--json]`: parses source text from
  stdin with the grammar chosen for the path and reports every syntax error
  with its position. `code-kb` uses it in place of its own tree-sitter grammars.
- Source and current docs name `code-kb` instead of Miller. That sweep changed
  prose inside `language_capabilities.capability_gaps`, declared as
  `classification: compatible` under `## 3.0.0` in
  `docs/contracts/extraction-output-changes.md`.

SQLite schema v7, report schema v3, extraction contract, identity epoch,
parser inventory, fixtures, and external dependency graph are unchanged.
