## Scope

`v2.8.1` publishes the GLM review remediation on top of `v2.8.0`. It is a
correctness, contract-honesty, and writer-hardening patch release. It fixes
reviewed extraction edge cases across backend HTTP boundaries, frontend route
precision, JavaScript literal parsing, Vue script masking, data-domain facts,
artifact writer dedupe/WAL behavior, JSONL ordering, and raw metadata
compaction. It does not add a new public fact family.
