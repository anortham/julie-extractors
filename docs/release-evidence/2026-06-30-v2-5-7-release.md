## Superseded v2.5.6

`v2.5.6` was published successfully, then superseded by this patch release.
The release-commit push CI for `v2.5.6` failed clippy because
`react_route_definition_fact` had too many arguments under
`clippy::too_many_arguments`.

`v2.5.7` keeps the framework route facts from `v2.5.6` and refactors the React
route-definition helper without changing emitted fact metadata.
