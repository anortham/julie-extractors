## Contract Notes

- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- `EXTRACTION_CONTRACT_VERSION` retains the
  `containing-symbol-binding-v2` marker introduced on the `v2.6.x` line.
- Structural-fact containing-symbol binding now rejects same-line child symbols
  whose byte span is contained by the fact.
- Same-line React/Vue route object facts no longer bind child property symbols
  such as `id`, `index`, or `path`; module-level route objects with no
  enclosing scope-bearing owner stay `NULL`.
- Parser dependency versions are unchanged.
- The release packages do not add Julie MCP/server/daemon/search/embedding,
  watcher, dashboard, registry, editing, or runtime behavior.
