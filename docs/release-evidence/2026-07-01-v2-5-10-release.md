downstream bridge tracing. It keeps the existing SQLite, JSONL, and report
schema integers at `3`, while moving the public extraction contract marker from

## Contract Notes

- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- `EXTRACTION_CONTRACT_VERSION` includes `web-route-facts-v3`.
- `vue.route_definition.v1` now includes plain JS/TS/JSX/TSX vue-router
  configs gated on local `vue-router` imports.
- Vue and React child route definitions can include `parent_route_path` and
  `effective_route_template`.
- React and Next navigation references now emit implied `verb=GET` metadata,
  matching Vue and Nuxt reference families.
- `nextjs.file_route.v1` strips App Router parallel slots and intercepting
  markers from `route_path` while recording those conventions as metadata.
- Next Pages Router file routes require local Next evidence, reducing React SPA
  `pages/` false positives.
- Nuxt optional and mixed static/dynamic file-route segments normalize with
  Nuxt-specific semantics.
- `htmx.attribute.v1` recognizes `data-hx-*` and records `data_prefix=true`.
- Parser dependency versions are unchanged.
- The release packages do not add Julie MCP/server/daemon/search/embedding,
  watcher, dashboard, registry, editing, or runtime behavior.
