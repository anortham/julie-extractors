## Scope

`v2.7.0` ships the backend HTTP boundary coverage lane (16 new route/mount
structural-fact families across 10 languages, the `http.client_request.v1`
five-language backend extension, the ASP.NET `normalized_route_template`
addition, and the `backend-http-boundary-v1` contract marker) plus the full
resolution of the 38-finding pre-release code review recorded in
`docs/reviews/2026-07-02-backend-http-boundary-review-findings.md`.

  `http.client_request.v1` extension are additive; existing fact families are
  unchanged except the four sanctioned metadata corrections called out in the
  release notes (Spring `attribute_kind` on `method =` mappings, gin/echo
  `api_style="call_routing"`).
- Parser dependency versions are unchanged.
- The release packages do not add Julie MCP/server/daemon/search/embedding,
  watcher, dashboard, registry, editing, or runtime behavior.
