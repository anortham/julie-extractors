## Superseded v2.5.4

`v2.5.4` was published successfully, then superseded by this patch release.
The follow-up docs CI for `v2.5.4` failed in dependency policy after
`cargo-deny` reported `RUSTSEC-2026-0190` for `anyhow 1.0.102`.

`v2.5.5` updates `anyhow` to `1.0.103` and keeps the `v2.5.4` Vue
route-reference structural facts. The first `v2.5.5` release-candidate CI run
then failed contract-tier validation because the capability matrix claim for
`vue.route_reference.v1` did not have fixture evidence. The final release
commit adds that Vue fixture evidence, and the release-commit CI passed.
