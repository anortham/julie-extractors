## What shipped

Hardening for the six defects a four-way cross-model adversarial review
(Codex + Grok over v2.21.0→v2.23.0, both repos) found in v2.23.0's new scale
paths: the binary spool now fails closed on truncation/corruption with a
release-mode snapshot-completeness guard; bulk-load eligibility is a true
first-build predicate; a failed durability restore surfaces both errors and
poisons the writer; a post-commit journal-restoration failure is the distinct
`JournalRestoreFailedAfterCommit` with `"committed": true` in the CLI
diagnostic; the extraction pool never falls back to an unverified stack; and
JSONL export emits `null` for `identifier.code_context` unconditionally,
making the documented contract true for upgraded artifacts. Fix commit
`afbe08b` (8 files, +885/−64); full notes in
`docs/release-notes/v2.23.1.md`.
