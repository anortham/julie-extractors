# julie-extract 3.3.0 release verification

Published v3.3.0 release verification.

## Scope

- Qt C++ first-class support: a token-level pre-pass blanks Qt macros before
  the parse on the scan and check paths; `Q_PROPERTY` lines become `property`
  rows and `cpp.qt_property.v1` facts; signals-section methods become `event`
  rows; slots, invokables, and QML element macros become metadata; forward
  declarations emit no class row; a declared constructor or destructor emits one
  row; method signatures keep their declared return type and carry `override`
  after the parameters. See `docs/release-notes/v3.3.0.md`.
- SQLite schema v7, report schema v3, and the identity epoch (10) are unchanged.
  `EXTRACTION_CONTRACT_VERSION` gains the suffix `qt-cpp-v1`.
- The `## 3.3.0` entry in `docs/contracts/extraction-output-changes.md` is
  classified `compatible`; `cargo xtask compat-check` against the published
  3.2.0 binary reported every difference as declared.
