# julie-extract 2.43.0 release verification

Published v2.43.0 release verification.

## Scope

- Adds the `facts` extraction level: the symbol core plus `structural_facts`,
  `literals`, and the `type_usage` and `member_access` identifiers, with no
  call or variable-reference identifiers, type-argument usages, or source
  regions. Built for `code-kb`, which requests it on every new artifact.

SQLite schema v7, JSONL v5, report schema v3, family-store schema v2,
extraction contract, identity epoch, parser inventory, fixtures, and external
dependency graph are unchanged. `symbols` and `full` levels are unchanged.
