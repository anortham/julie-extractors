Resolution without a mutable monolith.

Ph2c proves the resolver mechanism first, then adds durable bases, cumulative deltas, exact view bindings, and three public adapters.

Branch: codex/index-store-ph2c
Hard stop: G1–G5 before schema v2

Interface

One deep session

Anti-joins, candidate loads, phase visibility and overlay writes stay together. Policy sees semantic identities, never table names.

Storage

No ATTACH, no long snapshot

Bounded immutable family reads feed a separate scratch database. Final CAS revalidates manifest and delta head.

Identity

Immutable base

(manifest_hash, resolver_output_epoch), only after every visible version has L2.

Diff

Cumulative delta

Identifier replacements, pending replacements and pending tombstones recreate a fresh exact result.

Concurrency

Short writer lease

Compute heartbeats a resolve claim off-lease; only registration and publication take the writer lease.

Compatibility

Schema v2 refuses v1

No migration in Ph2c. The store is unreleased; Ph2d owns promotion and migration.

Adapters

Real transformations

Export streams a pinned exact view into v3. From-artifact transforms rows into versions/base/binding; neither copies a database wholesale.
