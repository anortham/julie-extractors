Never touch

  • Legacy behavior — no resolver-output change without pinned-oracle proof and an explicit epoch decision.
  • Writer fairness — no whole-corpus pass under the store-writer lease.
  • Ph2d/Ph3 scope — no general GC, release, Miller reader wiring, or dashboard work.

Held constant

  • G3b ceiling — 0.50 for every pair in every run, never averaged.
  • Resolution identity — semantic rows exclude legacy resolved-at revision bookkeeping.
  • Visibility — only one immutable manifest generation supplies extraction rows.

Verification gates

  • G1/G2 — both resolution tables, persisted roundtrip, deletions, and totality.
  • State machine — rename tears, CAS loss, stale deltas, pins, takeover, and reconciliation.
  • Parity — every supported language across incremental, fresh, export, and legacy paths.
