# 3.3.1 release preparation

This document prepared the 3.3.1 release candidate on
`review/qt-release-quality`. The user authorized a local commit, merge to
`main`, and release of 3.3.1 on 2026-09-22. The release published successfully
at `2026-09-22T15:15:59Z`; the closeout records its evidence and advances the
published pointer.

- Package versions: `julie-extract-artifact`, `julie-extract-cli`, and
  `julie-extractors` are prepared as 3.3.1, with matching `Cargo.lock` entries.
- Extraction contract: `qt-reference-corrections-v1` is appended to
  `EXTRACTION_CONTRACT_VERSION` because canonical extraction rows change.
- Compatibility: SQLite schema remains 7, report schema remains 3, and identity
  epoch remains 10. The 3.3.1 ledger entry is `compatible`; consumers rebuild
  artifacts after replacing the binary.
- Product changes: QML pending/ownership edges, Qt property metadata keys,
  JavaScript QML-directive location ids, and corrected Qt macro parsing.
- Evidence: [Qt release review](./2026-09-22-qt-release-review.md) and
  [Claude review follow-up](./2026-09-22-claude-qt-review.md).

The external review inspected a pre-fix snapshot and did not rerun on the final
corrected tree. Lead verification passed the default, contract, syntax API, and
xtask tiers on the frozen 3.3.1 source commit. Performance evidence remains
with the review artifacts.

See [post-Claude corpus evidence](./2026-09-22-v3-3-1-post-claude-corpus.json)
for the final quality and p95 timing comparison against v3.3.0.
