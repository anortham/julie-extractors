# v2.1.2

This patch prepares the v2.1 source-region product line for release after the
project hardening review.

## Fixes

- Preserved partial discovery metadata during artifact updates, including
  capability-revision counts and explicit no-op delete handling.
- Hardened JSONL export and report paths so failed exports do not leave partial
  output files and report-only commands validate unsupported or stale artifacts.
- Cleaned unsupported-update history, scan report profile output, and source-aware
  `.h` language routing.
- Restored TypeScript URL literal persistence for awaited generic client calls
  such as `axios.get<T>(...)` and `axios.put<T>(...)`.
- Normalized extractor code and tests to pass workspace clippy with
  `-D warnings` across all targets and features.

## Release Hardening

- Added a cargo-deny dependency policy gate to CI and the local verification
  flow.
- Tightened release preflight coverage for crate versions, package manifest
  inputs, and target-specific binary suffixes.
- Fixed release packaging for Windows targets by staging `julie-extract.exe`
  under target-specific package paths.
- Added a default-test wall-clock budget tripwire and convention coverage so
  slow gates stay out of the default route.

## Contract Changes

- Rust package versions change from `2.1.1` to `2.1.2`.
- CLI commands, exit codes, SQLite schema version, JSONL schema version, JSON
  report schema version, and artifact integer `extract_contract_version` remain
  unchanged.
- Rust crate `EXTRACTION_CONTRACT_VERSION` remains
  `2026-06-03.ecmascript-swift-shape-v3.source-regions-v1`.
- Parser dependency versions are unchanged.
