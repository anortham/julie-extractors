# julie-extract 2.42.1

classification: compatible

This release expands the hard-exclusion directory list in file discovery to prevent indexing agent artifacts, IDE metadata, git worktrees, and virtual environments. Extraction output, schemas, and the extraction identity epoch are unchanged.

## Hard-excluded directories

The discovery engine refuse list (`HARD_EXCLUDE_DIRS`) now unconditionally ignores:
- **Code intelligence and agent metadata:** `.code-kb`, `.claude`
- **Git worktree directories:** `.worktrees`, `worktrees`
- **IDE configuration directories:** `.idea`, `.vscode`, `.vs`
- **Python virtual environments & isolation:** `.venv`, `venv`, `.env`, `.tox`

These directories are ignored unconditionally before ignore files are parsed, preventing unbounded recursive indexing of virtual environments or circular references when analyzing workspaces containing agent stores or worktrees.

## Compatibility and rollout

- Artifact schema remains 7, JSONL export contract remains v5, report schema remains 3, and family-store schema remains 2.
- Extraction identity epoch remains 10, so unchanged files are not re-extracted.
- Fully compatible patch release; no re-extraction is required.
