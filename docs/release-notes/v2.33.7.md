# julie-extract v2.33.7

v2.33.7 is a compatible store-scope patch. Public CLI, report, schema, and store
contract surfaces stay the same.

## Ubiquitous names stay out of delta expansion

A small C# save used to expand every journal name into every file that shared
that name. Common names such as `Scan` then crossed the scope-crossover limit
and fell back to a full-view resolve.

The planner now drops a name when `identifier.name` appears in more than 16
files in the current view. Names that never appear as identifiers stay in the
worklist. Changed files stay selected. One journal-changed file still never
promotes to full.

On the Miller family store, a three-file C# save stayed scoped (17 files, 6
names). The previous run of that shape crossed over to 1,553 files.

## Compatibility

No public CLI, report, schema, or store contract version changes. Existing store
files, resolution publication, fencing, crash-recovery, and package integration
points remain compatible with v2.33.6.
