# julie-extract 3.3.1

classification: compatible

This patch corrects Qt/QML extraction output without changing the SQLite or
report schema. Every canonical-output change is declared in [the
extraction-output ledger](../contracts/extraction-output-changes.md) under
`3.3.1`.

## Changed

- QML calls, pending calls, and handler calls now use the owning inline
  component and respect local and parameter shadowing. Nested-object `parent`
  and `this` bindings point to the exact object; same-line inline-component
  `extends` rows use byte-exact ownership.
- Qt `Q_PROPERTY` symbols and `cpp.qt_property.v1` facts now include optional
  `designable`, `scriptable`, `stored`, `user`, and `revision` metadata when
  present.
- JavaScript QML-directive imports and pragma facts end before trailing line
  comments, restoring their source spans and location-derived ids.
- C++ Qt preprocessing preserves ordinary `Q_NULLPTR` expressions and runtime
  calls, restores declaration-position macro handling, recognizes numeric digit
  separators, and leaves non-class `signals:` and `slots:` labels intact.

## Compatibility

- SQLite schema remains 7, report schema remains 3, and extraction identity
  epoch remains 10. `EXTRACTION_CONTRACT_VERSION` adds
  `qt-reference-corrections-v1` because canonical rows change.
- Replace the binary and rebuild affected artifacts. No schema migration is
  required.
- Qt property metadata keys are optional. Existing readers continue to parse
  rows that omit them.

## Evidence

- The frozen candidate passed the default tier (4,537 passed), contract tier
  (187 passed), syntax API contract (8 passed), xtask tier (119 passed), and
  strict language report (`silent_cells=0`, `quality_bar_debts=0`).
- Corpus scans found no failed files. QML diagnostic spans match 3.3.0;
  Kirigami C++ diagnostics remain 31; Plasma C++ diagnostics decrease from 298
  to 297.
- C++ corpus p95 rises about 14%: Plasma 7.62 s to 8.68 s and Kirigami 0.77 s
  to 0.88 s. The 169 KB single-line Qt macro case improves 40.8%, from 3.73 s
  to 2.21 s p95. The corpus measurements do not isolate the source of the
  regression.
- Full corpus methods, counts, timings, and limitations are recorded in the
  [post-review corpus evidence](../reviews/2026-09-22-v3-3-1-post-claude-corpus.json).
