# julie-extract 3.1.3

classification: compatible

This release adds a Linux ARM64 binary to every published release, for hosts
such as Asahi Linux on Apple Silicon and Snapdragon laptops. No extraction
behavior changes.

## Added

- Release asset `julie-extract-v3.1.3-aarch64-unknown-linux-gnu.tar.gz`,
  built on the native GitHub `ubuntu-24.04-arm` runner. The package layout
  matches the other targets: `dist/aarch64-unknown-linux-gnu/julie-extract`
  and its SHA-256 checksum file, plus the same contract and release docs.
- `cargo xtask release preflight` and `cargo xtask release package` accept
  `aarch64-unknown-linux-gnu`. Preflight now checks six targets.

## Compatibility

- SQLite artifact schema remains 7 and report schema remains 3.
- Extraction contract, identity epoch, parser inventory, golden fixtures, and
  extractor output are unchanged. An artifact built by 3.1.1 or 3.1.2 needs no
  rebuild.
- The Linux ARM64 binary links against glibc 2.39, the same floor as the
  Linux x86_64 binary.
- The five existing targets keep their asset names and package layout.

## Evidence

- `cargo test -p xtask`: passes with the new target in the workflow contract test.
- `cargo xtask release preflight --version 3.1.3`: exit 0, 6 targets.
- The release workflow run for the `v3.1.3` tag is the first build of the
  Linux ARM64 binary; its result is recorded in the release-evidence document.
