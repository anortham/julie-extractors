# v2.5.6

This patch release supersedes `v2.5.5` by adding framework route facts for
Miller bridge coverage. It keeps the durable SQLite and JSONL artifact schemas
at version `3`.

## Features

- Added `aspnet.minimal_api.route_group.v1` facts for literal ASP.NET minimal
  API `MapGroup` route prefixes.
- Added `effective_route_template` metadata to grouped ASP.NET minimal API route
  calls when a route call is made through a captured group variable.
- Added `vue.route_definition.v1` facts for static Vue Router route objects with
  literal `path` values and optional route/component metadata.
- Added `react.route_reference.v1` and `react.route_definition.v1` facts for
  static React Router `Link`/`NavLink`, `<Route>`, route object, and index-route
  patterns.
- Added `nextjs.route_reference.v1` and `nextjs.file_route.v1` facts for static
  `next/link` targets and Next.js App Router / Pages Router page routes.

## Contract Changes

- Rust package versions change from `2.5.5` to `2.5.6`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
