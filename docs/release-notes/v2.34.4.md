## Compatibility

Artifacts stay schema 7, JSONL stays contract v5, family stores stay store
schema 2, and store format epoch stays 1. Extraction identity epoch is 4.

Consumer action: replace the binary and re-extract or rebuild standalone
artifacts, or let epoch-4 file versions populate on the next family-store
import or update.
