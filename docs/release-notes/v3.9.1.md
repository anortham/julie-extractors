# julie-extract 3.9.1

classification: compatible

Patch release corrects C# call-argument types introduced in 3.9.0 and fixes the
schema 7 to schema 8 migration instructions.

## Fixed

- C# `arg_types` now respects local and parameter visibility in blocks, loops,
  `catch`, `using`, and `fixed` scopes. `typeof(…)` reports `System.Type`.
- C# integer argument types account for literal value, radix, and suffix;
  unsupported or out-of-range values remain `null`.
- Schema 7 artifacts must be re-extracted into a new schema 8 database path.
  `scan --force` does not migrate a schema 7 artifact in place.

## Compatibility

- SQLite schema remains 8, report schema remains 3, and extraction identity
  epoch remains 10. `EXTRACTION_CONTRACT_VERSION` advances
  `csharp-argument-types-v1` to `csharp-argument-types-v2`.
- Refresh a 3.9.0 schema 8 artifact with `julie-extract scan --root <project>
  --db <artifact.db> --force` before incremental use with 3.9.1. For schema 7
  artifacts, create a new database and replace the old file only after readers
  are closed.
