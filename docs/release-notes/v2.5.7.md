# v2.5.7

This patch release supersedes `v2.5.6`. It keeps the framework route facts from
`v2.5.6`, fixes the release-commit clippy gate, and keeps the durable SQLite and
JSONL artifact schemas at version `3`.

## Features

- Retains `aspnet.minimal_api.route_group.v1` facts for literal ASP.NET minimal
  API `MapGroup` route prefixes.
- Retains `effective_route_template` metadata on grouped ASP.NET minimal API
  route calls when a route call is made through a captured group variable.
- Retains `vue.route_definition.v1` facts for static Vue Router route objects
  with literal `path` values and optional route/component metadata.
- Retains `react.route_reference.v1` and `react.route_definition.v1` facts for
  static React Router `Link`/`NavLink`, `<Route>`, route object, and index-route
  patterns.
- Retains `nextjs.route_reference.v1` and `nextjs.file_route.v1` facts for
  static `next/link` targets and Next.js App Router / Pages Router page routes.

## Fixes

- Refactored the React route-definition fact helper so
  `cargo clippy --workspace --all-targets --all-features --no-deps -- -D warnings`
  passes under the CI toolchain.

## Contract Changes

- Rust package versions change from `2.5.6` to `2.5.7`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
