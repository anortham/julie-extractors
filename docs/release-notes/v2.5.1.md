# v2.5.1

This patch release fixes source decoding for BOM-marked UTF-16 SQL files. It
keeps the durable SQLite and JSONL artifact contracts at version `3`.

## Fixes

- `julie-extract` now decodes UTF-16LE and UTF-16BE source files when they have
  a byte order mark before passing text to language extractors.
- UTF-16 source files preserve their original byte hash and byte count for
  incremental indexing and diagnostics.
- Malformed UTF-16 input still reports a read failure with the original content
  hash and byte count.

## Contract Changes

- Rust package versions change from `2.5.0` to `2.5.1`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
