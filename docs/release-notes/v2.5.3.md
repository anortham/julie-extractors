# v2.5.3

This patch release adds missing SQLite indexes for large incremental artifact
updates. It keeps the durable SQLite and JSONL artifact schemas at version `3`.

## Fixes

- Added indexes used by writer delete paths and foreign-key cleanup paths for
  relationships, pending relationships, type facts, symbol annotations, type
  argument usages, type arguments, literals, and parse diagnostics.
- Large scans that rewrite or delete many file rows avoid table scans in these
  cleanup paths.

## Contract Changes

- Rust package versions change from `2.5.2` to `2.5.3`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
