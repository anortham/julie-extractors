# v2.2.1

This patch release adds framework-aware structural facts for ASP.NET minimal
APIs, htmx attributes, and Alpine directives while keeping the v3 extraction
contract unchanged.

## Features

- Emits `aspnet.minimal_api.route.v1` structural facts for C# minimal API route
  mappings, including HTTP verb, route template, and handler symbol metadata
  when available.
- Emits `htmx.attribute.v1` structural facts for htmx attributes in HTML and
  Razor markup, including normalized attribute names and request target paths
  for route-bearing attributes.
- Emits `alpine.directive.v1` structural facts for Alpine `x-*`, `@`, and `:`
  directives in HTML and Razor markup, including directive name and expression
  metadata.
- Publishes the new pattern IDs through persisted capability rows and
  `julie-extract languages --json` capability output.

## Fixes

- Avoids treating markup-like text inside HTML or Razor raw-text script content
  as real htmx or Alpine markup facts.

## Contract Changes

- Rust package versions change from `2.2.0` to `2.2.1`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
