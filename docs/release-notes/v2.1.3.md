# v2.1.3

This patch fixes file discovery policy gaps found during Miller beta
verification.

## Fixes

- Hard-excludes `vendor/` directories during discovery so vendored source trees
  are not indexed by default.
- Applies ancestor `.gitignore` files when scanning a nested workspace inside a
  larger Git repository.
- Recognizes Git worktree and submodule layouts where `.git` is a file, not
  only repositories where `.git` is a directory.

## Contract Changes

- Rust package versions change from `2.1.2` to `2.1.3`.
- CLI commands, exit codes, SQLite schema version, JSONL schema version, JSON
  report schema version, and artifact integer `extract_contract_version` remain
  unchanged.
- Rust crate `EXTRACTION_CONTRACT_VERSION` remains
  `2026-06-03.ecmascript-swift-shape-v3.source-regions-v1`.
- Parser dependency versions are unchanged.
