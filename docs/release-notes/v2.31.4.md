# julie-extract v2.31.4

Patch release that removes avoidable work from exact family-store resolution
without changing the store schema, resolver epoch, or published contracts.

## Bounded exact resolution

Resolution now reuses validated readers and prepared statements, filters
candidate lookups in SQL, streams bounded caches, and batches relationship
identifier hydration. Tier spill remains bounded, and all existing exactness
and publication fences are preserved.

## Performance

The same Miller repository replay improved from 6m20.55s to 2m24.54s, a 2.6x
speedup. Both runs produced the same exact result: 37,965 gaps across 98 files
and 416,361 identifiers. The repaired run used about 90 MB peak resident memory.

## Compatibility

The versioned family-store schema, manifests, resolution bases, resolver epoch,
and standalone artifact contract are unchanged. Miller can adopt this patch by
updating only its pinned producer archives and checksums.

## Verification

Formatting, strict Clippy, default, contract, release preflight, package-list,
performance, and mechanism gates are required for this candidate.

This is the current published release. The four target packages were published
from tag `v2.31.4` at commit `16f25f2f8c9ed25e0e37644411db1340eb3df37c`
and verified after download.
