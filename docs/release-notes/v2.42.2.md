# julie-extract 2.42.2

classification: compatible

This maintenance release reduces internal duplication in extraction fact construction, capability serialization, artifact bulk loading, and test execution. It removes a retired development-only reference-resolution report generator and its test.

## Compatibility

- SQLite artifact schema remains 7, JSONL export contract remains v5, report schema remains 3, and family-store schema remains 2.
- Extraction contract and identity epoch remain unchanged; existing artifacts and unchanged files do not require migration or re-extraction.
- Emitted facts, identifiers, JSON shapes, capability fingerprints, and package dependencies are unchanged.
- The retired report generator had no found invocation in this repository or the available Miller, Julie, and code-kb checkouts. Historical artifacts remain preserved.

## Performance

This release makes no runtime performance claim. The changes reduce code and test maintenance surface.
