# v0.1.0

Status: release candidate staged for local review. No release assets have been
published from this repository.

## Shipped Product Surfaces

- CLI: `julie-extract scan`, `update`, `delete`, `info`, `export`, and
  `languages`.
- SQLite artifact contract: v1, primary durable output.
- SQLite artifacts persist parser inventory and language capability snapshot
  rows.
- JSONL export contract: v1, secondary export and streaming format.
- JSON report contract: v1 reports for CLI automation.
- Rust crate: secondary in-process extraction API.

```bash
cargo xtask release package-list
```
