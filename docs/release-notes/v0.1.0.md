# v0.1.0

Status: release-readiness notes for the first standalone `julie-extract`
package. No release assets have been published from this repository.

## Shipped Product Surfaces

- CLI: `julie-extract scan`, `update`, `delete`, `info`, `export`, and
  `languages`.
- SQLite artifact contract: v1, primary durable output.
- JSONL export contract: v1, secondary export and streaming format.
- JSON report contract: v1 reports for CLI automation.
- Rust crate: secondary in-process extraction API.

## Package Contents

The release package manifest is generated by:

```bash
cargo xtask release package-list
```

Packages contain:

- `julie-extract` binary
- SHA-256 checksum file
- CLI, SQLite, JSONL, and report contracts
- product-boundary and schema-principles docs
- testing and release docs
- this release note

Package staging command:

```bash
cargo xtask release package --version 0.1.0 --target <target> --out-dir <path> --binary <path>
```

## Evidence

- Dogfood evidence: `docs/release-evidence/v0.1.0-dogfood.md`
- Dogfood result: scan, info, and JSONL export reports all `status=ok`
- Dogfood artifact: 1000 files, 32642 symbols, 212945 JSONL records
- Dogfood performance metrics are report-only for v0.1.0

## Known Boundaries

- This repo does not ship Julie MCP/server/daemon/search/embedding/watcher,
  dashboard, or editing behavior.
- JSONL is secondary to SQLite.
- The CLI is the primary integration surface; Rust APIs are secondary.
- Release package staging is local. Publication to GitHub or a package registry
  is not part of these notes.
