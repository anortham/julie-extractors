# v2.5.10

This patch release hardens web route structural facts for downstream bridge
tracing. It supersedes `v2.5.9`.

## Fixes

- Keeps Vue SFC template scanning open across nested `<template>` slot blocks,
  so route references after scoped slots are emitted.
- Emits `vue.route_definition.v1` from plain JavaScript, JSX, TypeScript, and
  TSX files that import `vue-router`.
- Fixes route-object attribution when nested objects such as `meta` appear
  before a `path` key.
- Emits Vue and React child route definitions with parent and joined effective
  route metadata.
- Strips Next.js App Router parallel route slots and intercepting-route markers
  from URL paths while recording those conventions in metadata.
- Suppresses `nextjs.file_route.v1` for plain React SPA `pages/` folders unless
  a Pages Router file has local Next evidence.
- Normalizes Nuxt optional params and mixed static/dynamic filename segments.
- Recognizes `data-hx-*` htmx attributes in HTML and Razor and normalizes them
  to canonical `hx-*` attribute names.

## Contract Changes

- Rust package versions change from `2.5.9` to `2.5.10`.
- `EXTRACTION_CONTRACT_VERSION` changes from `web-route-facts-v2` to
  `web-route-facts-v3`.
- `react.route_reference.v1` and `nextjs.route_reference.v1` now include
  `verb="GET"` to match Vue and Nuxt navigation references.
- `nextjs.file_route.v1` may include `parallel_route_segments`,
  `intercepting_route_markers`, and `intercepted_route_segments`.
- `vue.route_definition.v1` and `react.route_definition.v1` may include
  `parent_route_path` and `effective_route_template`.
- `htmx.attribute.v1` may include `data_prefix=true` for `data-hx-*`
  attributes.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
