# v2.5.2

This patch release fixes filename-derived top-level symbols for Razor and
GDScript component/script files. It keeps the durable SQLite and JSONL artifact
schemas at version `3` and bumps the extractor output-shape marker.

## Fixes

- Razor `.razor` files now emit a public top-level component symbol named from
  the filename. Explicit `@namespace` directives are used in the component
  signature when present.
- GDScript files with top-level resource-path extends statements, such as
  `extends "res://base_controller.gd"`, now emit the filename-derived implicit
  script class.
- Updated Razor and GDScript fixture evidence records the new top-level symbols,
  parented child symbols, and related containment/relationship metadata.

## Contract Changes

- Rust package versions change from `2.5.1` to `2.5.2`.
- `EXTRACTION_CONTRACT_VERSION` changes to include
  `file-derived-component-symbols-v1`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
