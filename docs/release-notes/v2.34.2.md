# julie-extract v2.34.2

v2.34.2 promotes test-role metadata on symbols the extractors already emit
for QML, GDScript, Bash, and Scala, and records R `test_lifecycle` as
not applicable.

## Test-role flags

Symbols that were already extracted now carry the matching role flags:

- QML: `TestCase` is `test_container`; `initTestCase` / `cleanupTestCase` /
  `init` / `cleanup` are `test_lifecycle`.
- GDScript: `GutTest` is `test_container`; `before_each` / `after_each` /
  `before_all` / `after_all` are `test_lifecycle`.
- Bash: `setup` / `teardown` are `test_lifecycle`.
- Scala: ScalaTest `beforeEach` / `afterEach` / `beforeAll` / `afterAll` are
  `test_lifecycle`. The Scala golden mixes `BeforeAndAfterEach`.

R keeps `test_case` and `test_container`. `test_lifecycle` is
`not_applicable`: testthat has no per-call lifecycle DSL. File-level
testthat `setup.R` / RUnit `.setUp` stay out of this release.

## Compatibility

classification: compatible

No contract changes against v2.34.1. Artifacts stay schema 7, JSONL stays
contract v5, family stores stay store schema 2, and reports are unchanged.

Consumer action: replace the binary. Existing artifacts pick up the new
flags on the next extract.
