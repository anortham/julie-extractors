# v2.5.5

This patch release supersedes `v2.5.4` by updating `anyhow` after the
post-release docs CI run reported `RUSTSEC-2026-0190`. It keeps the Vue
route-reference structural facts from `v2.5.4` and keeps the durable SQLite and
JSONL artifact schemas at version `3`.

## Fixes

- Updated `anyhow` from `1.0.102` to `1.0.103` to satisfy the RustSec advisory
  reported by `cargo-deny`.
- Superseded `v2.5.4`, whose release workflow passed but whose follow-up docs
  CI failed after the advisory became visible to dependency policy.

## Features

- Retains `vue.route_reference.v1` structural facts for literal Vue route
  targets.
- Route-reference facts are emitted for `<RouterLink to="...">`,
  `<router-link to="...">`, bound literal `:to="'...'"`, and literal
  `$router.push("...")` / `$router.push('...')` handler calls.

## Contract Changes

- Rust package versions change from `2.5.4` to `2.5.5`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
