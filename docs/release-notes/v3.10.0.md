# julie-extract 3.10.0

classification: incompatible for readers of CSS custom functions and of Java
and Scala construction sites

Minor release that closes the extractor gaps code-kb recorded for 3.9.1:
import sources in twelve more languages, anonymous class owners, argument
types for overload choice in six more languages, and fixes for Dart, C test
frameworks, R superassignment, SwiftPM and Zig build facts, and CSS custom
functions. `docs/contracts/extraction-output-changes.md` lists every rule.

## Added

- Import rows carry `source` (the module or path as written) and `form` (the
  directive) in C, C++, CSS, Bash, PowerShell, R, Ruby, F#, Dart, PHP,
  GDScript, and Java. New import rows for Ruby `load` and `autoload`, PHP
  `require` and `include`, and GDScript `preload` and `load`. Java wildcard
  imports carry `wildcard: true`.
- Anonymous classes get their own `class` row (`anonymous_class_L<line>`, `type:
  anonymous_class`) with their members and supertypes in Java, Kotlin, Scala,
  JavaScript, TypeScript, TSX, JSX, Vue, F#, and Ruby, as PHP already had.
- Call identifiers carry `arg_types` in Java, Kotlin, Scala, C++, VB.NET, and
  Swift, `arg_names` for Kotlin and Scala named arguments, and `arg_labels` for
  Swift. Scala, VB.NET, and Swift calls gain `arg_count`.
- C tests are flagged from a `unity.h` include, Unity `RUN_TEST`, Check
  `START_TEST` and `tcase_add_*`, and CMocka registrations, also outside test
  paths.
- R `<<-` and `->>` write a write site, and a global that a function creates
  writes a top-level row.
- SwiftPM target facts carry `effective_path`, `path_origin`, and
  `package_name`; `Package@swift-<version>.swift` manifests give facts. Older
  `build.zig` module and artifact forms give facts.
- CSS custom function calls are `call` identifiers with the declared name and
  `arg_count`, with `calls` relationships to same-file declarations and pending
  calls otherwise.

## Changed

- Test labels with escapes (`test("adds \"three\"")`) name the test by the
  decoded text in sixteen languages.
- Ruby test-unit `sub_test_case` blocks are test containers.
- Java and Kotlin argument types read each member once, so a long block
  scans in linear time.
- A C or C++ call through a subscript names no callee.
- Java and Scala `new T(…)` write a `call` identifier instead of a
  `type_usage`; C++ and VB.NET constructions add a `call` identifier.
- A CSS `@function --name()` is a `function` row named `--name` (escapes
  decoded), not a `namespace` row.
- A Scala `def` inside a `def` is kind `function`.
- A Dart `library x;` before a declaration is a `namespace` row, not a
  `variable`.
- C/C++ include paths ignore a trailing comment; PowerShell `using module` keeps
  the whole module name.

## Compatibility

- SQLite schema remains 8, report schema remains 3, and extraction identity
  epoch remains 10. `EXTRACTION_CONTRACT_VERSION` adds the markers listed in the
  ledger entry for 3.10.0.
- Refresh a 3.9.1 artifact with `julie-extract scan --root <project> --db
  <artifact.db> --force` before incremental use.
