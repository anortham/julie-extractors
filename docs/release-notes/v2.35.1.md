# julie-extract v2.35.1

v2.35.1 is a compatible patch candidate. v2.35.0 remains the current
published release until the release workflow succeeds.

classification: compatible

## First-class QML extraction

- QML source, `qmldir`, and `.qmltypes` files now publish module, component,
  import, type, relationship, structural-fact, and source-region evidence
  through the existing SQLite and JSONL artifact contracts.
- Qt Quick Test roles distinguish runnable tests, benchmarks, lifecycle methods,
  and `_data` helpers, with focused continuous-test targets:
  `cargo xtask test language qml` and `cargo xtask test language qmldir`.
- The `tree-sitter-qmldir` parser is pinned and covered by dependency-policy,
  golden-fixture, capability, certification, and real-world verification.

## Compatibility

Artifacts stay schema 7, JSONL stays contract v5, family stores stay store
schema 2, and store format epoch stays 1. Extraction identity epoch is 5.
Existing v2.35.0 readers can read the unchanged artifact tables; replace the
binary and re-extract source trees, or let epoch-5 family-store file versions
populate on the next import or update.
