# julie-extract 3.1.2

classification: compatible

This release adds a Windows ARM64 binary to every published release. No
extraction behavior changes.

## Added

- Release asset `julie-extract-v3.1.2-aarch64-pc-windows-msvc.zip`, built on
  the native GitHub `windows-11-arm` runner. The package layout matches the
  other targets: `dist/aarch64-pc-windows-msvc/julie-extract.exe` and its
  SHA-256 checksum file, plus the same contract and release docs.
- `cargo xtask release preflight` and `cargo xtask release package` accept
  `aarch64-pc-windows-msvc`. Preflight now checks five targets.

## Compatibility

- SQLite artifact schema remains 7 and report schema remains 3.
- Extraction contract, identity epoch, parser inventory, golden fixtures, and
  extractor output are unchanged. An artifact built by 3.1.1 needs no rebuild.
- The four existing targets keep their asset names and package layout.

## Evidence

- `cargo test -p xtask`: passes with the new target in the workflow contract test.
- `cargo xtask release preflight --version 3.1.2`: exit 0, 5 targets.
- The release workflow run for the `v3.1.2` tag is the first build of the
  ARM64 binary; its result is recorded in the release-evidence document.
