# v2.14.0

This feature release closes the Terraform T-SQL parse-quality gap, hardens
Razor parsing, and updates the parser runtime and certified grammar set.

## T-SQL parse quality

- The six valid Terraform SQL files now produce zero `error` and zero `missing`
  diagnostics, down from 283 errors and one missing node.
- T-SQL DDL, batch, routine-parameter, trigger, and parser-backed `MERGE`
  fixtures preserve existing general-SQL extraction shapes.
- One shared SQL helper normalizes bracketed identifiers across extraction
  consumers, including escaped closing brackets.
- All five malformed T-SQL negative controls continue to emit diagnostics.
- `tree-sitter-sql` is pinned to the exact owned-fork revision
  `63ea933e464813d01cab5d7febcb0f77409c247b`.

## Razor parser hardening

- Razor expression extraction now uses the parser's public expression node
  kinds, including nested conditional and stable template syntax.
- An 85-input .NET 10 and .NET 11 preview documentation corpus classifies every
  remaining diagnostic as an explicit placeholder or pseudocode fragment.
- The 28 valid Terraform Razor files continue to produce zero diagnostics.
- `tree-sitter-razor` remains pinned to the certified revision
  `fba8571f06c06aa5acca01e3d762f5a5e78dc50f`.

## Parser runtime and grammar freshness
