# v2.5.4

This patch release adds Vue route-reference structural facts so downstream
consumers can bridge Vue route literals to backend routes. It keeps the durable
SQLite and JSONL artifact schemas at version `3`.

## Features

- Added `vue.route_reference.v1` structural facts for literal Vue route targets.
- Route-reference facts are emitted for `<RouterLink to="...">`,
  `<router-link to="...">`, bound literal `:to="'...'"`, and literal
  `$router.push("...")` / `$router.push('...')` handler calls.
- Non-route directives and nonliteral route expressions continue to avoid
  authoritative route facts.

## Contract Changes

- Rust package versions change from `2.5.3` to `2.5.4`.
- SQLite schema version remains `3`.
- Artifact integer `extract_contract_version` remains `3`.
- JSONL schema version remains `3`.
- JSON report schema version remains `3`.
- Parser dependency versions are unchanged.
- `fixtures/extraction/capabilities.json` now claims
  `vue.route_reference.v1`.
