# v2.1.1

This patch expands source-region extraction across the supported language
matrix.

## Fixes

- Added source-region collection for every supported language with parser-backed
  comment, string-literal, or embedded-language regions.
- Added C#, C, C++, Java, Go, Zig, VB.NET, PHP, Ruby, Swift, Kotlin, Scala,
  Dart, Elixir, Lua, QML, R, Bash, PowerShell, GDScript, Razor, SQL, Markdown,
  JSON/JSONC, TOML, YAML, CSS, and the existing web/script languages to the
  shared source-region coverage test.
- Reused the central language-spec doc-comment styles for source-region
  classification, avoiding a second hard-coded doc-comment syntax list.
- Added embedded-region metadata for Razor C# blocks and Markdown fenced code
  blocks.

## Domain Limits

- Regex remains domain-limited for source regions because the current contract
  has no regex-specific comment, string-literal, or embedded-language region
  kind.
