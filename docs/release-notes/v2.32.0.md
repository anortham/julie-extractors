# julie-extract v2.32.0

Minor release that makes validated scoped family-store resolution the default and retains an explicit
forced-full escape hatch.

## Incremental exact resolution

Manifest transitions now carry validated resolution-scope journals. Exact resolution reuses the
prior base and cumulative delta, recomputes a dependency-closed worklist, bulk-carries unaffected rows,
and atomically publishes either the scoped result or a safe full fallback. Exact-publication telemetry
records the mode, scope size, fallback reason, and phase timings durably across retries.

`JULIE_STORE_RESOLUTION_DELTA` is scoped when unset or set to `on`. Setting it to `off` preserves the
pre-change forced-full behavior.

## Rebase

An exact result rebases when cumulative replacements exceed one quarter of the ready base or exact-gap
storage exceeds 64 MiB. Rebase publishes a ready base and empty delta atomically; equality at either
threshold does not rebase.

## Compatibility

The store remains schema v2 and format epoch 1. The standalone v3 artifact, resolver-output epoch, and
caller-facing CLI report vocabulary are unchanged apart from additive resolution telemetry introduced
by this feature line.

## Verification

The deterministic faithful recorded-scale 98-file replay produced identical canonical semantic
digests and zero row differences in three runs. Scoped resolution completed in 18.35–18.68 seconds
versus 32.12–32.63 seconds forced full. Miller fast and Scale consumer suites, branch contracts,
strict Clippy, dependency policy, and secret scanning passed. Full evidence is in the
[dogfood ledger](../findings/2026-08-11-store-incremental-resolution-dogfood.md).
