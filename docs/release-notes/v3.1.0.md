# julie-extract 3.1.0

classification: compatible

This release stops marking markdown fenced code blocks as tests and limits
`symbol_annotations` and `complexity_metrics` to the `full` extraction level.
Both changes are declared in
[the extraction-output ledger](../contracts/extraction-output-changes.md) under
`3.1.0`.

## Changed

- A fenced code block in a standalone markdown file no longer carries the
  rustdoc test rule. Blocks with no info string, or an info string of `rust`,
  `no_run`, `compile_fail`, `rust,no_run`, or `rust,compile_fail`, previously
  set `is_test = 1` and `metadata_json.test_role = "test_case"`. Markdown now
  emits no test roles at all, and the markdown `language_capabilities` row
  moves `test_case` from `kind_coverage.test_detection.supported` to
  `not_applicable`.
- `symbol_annotations` and `complexity_metrics` are written only at
  `--level full`. A `symbols` or `facts` scan leaves both tables empty.
  `ExtractionLevel::includes_complexity_and_annotations` is the single gate,
  applied in `ExtractionResults::strip_to_level`.

## Compatibility

- SQLite artifact schema remains 7 and report schema remains 3.
- Extraction contract and identity epoch remain unchanged. No column, table, or
  JSON shape changes, so a reader built for 3.0.0 reads the new output
  correctly.
- `scan --level <symbols|facts|full>` values are unchanged.
- A consumer that already holds an artifact must rebuild it rather than rescan,
  because an unchanged file keeps its stored rows.
- A consumer that reads annotations or complexity metrics must scan at `full`.
- Emitted facts, identifiers, parser inventory, and external dependency graph
  are otherwise unchanged.

## Contract changes

- [The CLI contract](../contracts/cli.md) moves `symbol_annotations` and
  `complexity_metrics` out of the `symbols` level description and states that
  only `full` writes them.
- `ExtractionLevel::includes_complexity_and_annotations` is added to the Rust
  crate API. `is_rustdoc_test_case` is removed from the markdown extractor.

## Evidence

- `cargo test -p julie-extractors markdown::test_detection`: 1 passed.
- `cargo test -p julie-extractors extraction_levels`: 10 passed, including
  `only_full_level_carries_complexity_metrics_and_symbol_annotations` and
  `full_level_fixtures_actually_carry_complexity_metrics_and_symbol_annotations`.
- `cargo xtask release preflight --version 3.1.0`: exit 0.
