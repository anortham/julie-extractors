# v2.1.0

This release adds source-region extraction to the standalone extraction product.

## Features

- Added a `source_regions` SQLite row domain for comments, doc comments, string
  literals, and embedded language regions.
- Added `source_region` JSONL records after `literal` records and before
  `parse_diagnostic` records.
- Added report row counts for `source_regions`.
- Added extractor-level source-region collection for the first supported
  language set: Rust, JavaScript, JSX, TypeScript, TSX, Python, HTML, and Vue.

## Contract Changes

- SQLite schema version changes from `1` to `2`.
- Artifact integer `extract_contract_version` changes from `1` to `2`.
- JSONL schema version changes from `1` to `2`.
- JSON report schema version changes from `1` to `2`.
- Rust crate `EXTRACTION_CONTRACT_VERSION` adds the `source-regions-v1` marker.
- CLI command names, flags, status values, and exit codes are unchanged.

## Product Boundary

Source regions expose AST-bounded spans and optional metadata. This release does
not add search tables, embedding tables, raw AST storage, complete source text
storage, MCP behavior, watcher behavior, or workspace registry behavior.
