# v2.0.3

This is a patch release for the v2.0.x standalone extraction product line.

## Fixes

- Bumped the Rust extractor crate `EXTRACTION_CONTRACT_VERSION` to
  `2026-06-03.ecmascript-swift-shape-v3` so downstream Rust consumers that
  compose that string into their own index version can detect the v2.0.x
  Swift, JavaScript, and TypeScript extraction-shape changes.
- Added a changed-path guard for golden expected-output fixtures. Any
  `fixtures/extraction/**/expected.json` change now requires
  `crates/julie-extractors/src/lib.rs` in the same changed-path gate so
  reviewers explicitly consider whether `EXTRACTION_CONTRACT_VERSION` must move.
- Fixed changed-path routing for xtask edits so `cargo xtask test changed`
  runs `cargo test -p xtask` when xtask source or tests change.

## Contract Changes

- Rust crate extraction contract string changes from
  `2026-05-29.bridge-anchors-v2` to
  `2026-06-03.ecmascript-swift-shape-v3`.
- CLI commands, exit codes, SQLite schema version, JSONL schema version, and
  artifact integer `extract_contract_version` remain unchanged.
- JSON report schema remains version 1.
- Release package contents are unchanged.

- `cargo test -p xtask`
