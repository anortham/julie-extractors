# julie-extract v2.33.6

v2.33.6 is a compatible store-resolve performance patch. Public CLI, report, schema, and store
contract surfaces stay the same.

## File mini-index

Store resolve now loads one source file's symbols, imports, and type facts into a bounded
in-memory index (at most 2048 symbols and 4096 type facts per file, 256 files at a time).
File-local symbol, child, top-level, import, and type-fact lookups reuse that index instead
of one SQL query per probe.

A 2048-symbol cap covers every Miller family-store file that has identifier rows. Larger
files stay on SQL. If a file has more than 4096 type facts, symbols stay in RAM and type
facts stay on SQL. Answers are not truncated.

## Whole-pass name cache

Repo-wide "is this type name unique?" lookups now use the count query and keep the answer
for the whole resolve pass. Complete small name lists (at most 32 hits) are also kept.
An early stop does not store a partial list.

On the Miller family-store copy this removed 141,236 name-walk queries. Count queries stayed
near 9k.

## Compatibility

No public CLI, report, schema, or store contract version changes. Existing store files,
resolution publication, fencing, crash-recovery, and package integration points remain
compatible with v2.33.5.
