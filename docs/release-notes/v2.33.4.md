# julie-extract v2.33.4

v2.33.4 is a local release candidate for the versioned store. It is not published yet. This compatible
performance and reliability patch keeps the existing CLI, report, schema, and store contract surfaces intact.

## Accumulated resolution work

Scoped resolution now recognizes genuinely accumulated work: a still-scoped request with more than one
validated transition and strictly more than 25% unique current-manifest identifier coverage compacts the
base-plus-delta overlay into a fresh exact base with an empty delta. The existing inclusive 70% duplicated-read
full crossover remains unchanged, and the new decision is private to the resolution path.

The deterministic fixture publishes 79 sequential validated transition batches with 1,580 of 4,780 unique
identifiers selected (33.05%). Its broad resolve stayed scoped, rebased once, changed the base identity, left an
empty delta, and matched the full oracle's exact digest. The broad fixture resolve took 3,040 ms. Three warm
following one-file updates stayed scoped with one validated transition, did not trigger another accumulated-work
rebase, and had a 740 ms p95 wall time (733, 740, and 737 ms).

These are measurements of the deterministic accumulated-work fixture, not a cold whole-repository extraction or
a general latency guarantee.

## Writer-open schema repair

Opening a store writer now reapplies only the two additive non-unique symbol read indexes. Unique-invariant repair
remains behind validated recovery and import fallback, so a partially repaired store is not forced through unique
index recreation before its existing validation path can run.

## Terminal resolve waiters

Queued resolve waiters now observe durable `committed`, `acknowledged`, or `failed` request states and return the
stored result or failure immediately instead of waiting for the request timeout. Terminal cleanup and dead-lease
normalization remain in the existing idempotent path.

## Compatibility

No public CLI, report, schema, or store contract version changes. Existing store files, resolution publication,
fencing, crash-recovery, and package integration points remain compatible with v2.33.3.

## Verification

The integrated candidate passed the store-connection contract (28 tests), store-resolution contract (33 tests),
formatting, and whitespace checks. The accumulated-work fixture proved exact-digest equality, one-time base
rotation, empty-delta publication, and bounded following updates.

## Publication

This release candidate has not been published. Do not treat `v2.33.4` as the current stable release until its
package, source, and release workflows complete.
