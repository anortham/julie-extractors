# Release And Certification

## Commands

- Default gate: `cargo xtask test default`
- Contract gate: `cargo xtask test contract`
- Parser certification gate: `cargo xtask test certification`
- Changed-path gate: `cargo xtask test changed <path>...`
- Real-world smoke gate: `cargo xtask test real-world-smoke`
- Real-world release gate: `cargo xtask test real-world-release`
- Release package manifest: `cargo xtask release package-list`

`cargo xtask test real-world` aliases the release real-world profile.

## Parser Dependency Changes

The changed-path gate adds the full certification tier when these paths change:

- `Cargo.lock`
- `crates/julie-extractors/Cargo.toml`
- `crates/julie-extractors/src/language_spec/**`
- `crates/julie-extractors/src/registry*`

## Package Contents

Release packages contain only:

- `julie-extract` binaries
- SHA-256 checksum files for those binaries
- contract and architecture docs
- testing strategy and release-command docs
- versioned release notes from `docs/release-notes/`

The package manifest is generated by `cargo xtask release package-list`.
